# M1_기반·농사 기능 정의서

작성일: 2026-11-26 · 기준 문서: `../1.architecture/wall-geop-lupin 기획·설계서.md`, `01_요구사항 정의서.md`, `02_도메인 모델 및 데이터 포맷.md`, `03_시스템 설계.md`, `04_화면 설계.md`

M1 구현 범위와 규칙이다. 설계 문서와 다른 점은 이 문서가 우선하며, 구현 후 개발 명세의 "정의서와 달라진 점"에 남긴다.

## 1. 목표와 범위

PowerShell 탭에서 `lupin.exe`를 실행해 **씨앗을 사고 → 심고 → 물 주고 → 수확하고 → 팔고 → 땅과 농기구에 투자하는 한 바퀴**를 Claude Code 같은 화면에서 완성한다. 화면 틀, 입력, 저장, 위장(보스키, 접기)까지 이후 마일스톤의 바탕을 모두 만든다.

| 포함 | 요구사항 |
| --- | --- |
| 화면 틀: 헤더, 도트 농장 영역, 로그, 입력창, 안내 줄, 시작 환영 상자, 스피너 | FR-UI-01~10 |
| 입력: 편집, 이전 명령, 자동완성, 선택지, `Ctrl+C`, `Esc` | FR-CMD-01~10 |
| 시간: 배속, 하루·계절 표시, 꺼져 있던 시간(기본 상한 2시간), 절전 처리 | FR-TIME-01~03, 05~09 |
| 농사: 심기, 물 주기, 성장, 수확, 뽑기, 농기구 범위 제한 | FR-FARM-01, 03~11 |
| 구역: 칸·구역 구매, 페이지 전환(명령, 키, 마우스), 밭 클릭 | FR-FLD-01~05, 07 |
| 상점: `/shop`, `/buy seed`, 농기구 업그레이드 | FR-SHOP-01, 02, 05(농기구만), 06, 08 |
| 판매: `/sell` (기준가) | FR-MKT-04 |
| 위장: 가짜 프롬프트, 보스키, `/hide`, 탭 제목, 무음 | FR-HIDE-01~07 |
| 설정·저장: `/config`, 자동 저장, `.bak`, `/reset` | FR-SET-01~09 |
| 비기능 | NFR-01~10 |

| 제외 | 이유 |
| --- | --- |
| 밤 표시 (FR-TIME-04), 계절 제한 (FR-FARM-02), 계절 색 (FR-SEA-01) | M2. M1은 봄 색으로 그리고 모든 해금 작물을 계절과 상관없이 심을 수 있다 |
| 시세 변동, 판매 압력, 제철 배수 (FR-MKT-01~03, 05~06) | M2. M1은 기준가로 판다 |
| 작물 해금, 창고 업그레이드, `/inv`, `/map`, `/market` | M2 |
| 장비, 규칙, Caretaker (FR-EQP, FR-AUTO) | M3 |
| 기록, 프레스티지, 도감, 업적 (FR-REC, FR-PRS, FR-DEX) | M4 |

M2 이후 명령(`/market` 등)을 치면 "이후 업데이트에서 추가된다"고 알린다.

## 2. 확정한 결정

| 번호 | 결정 |
| --- | --- |
| K1 | M1 작물은 해금 비용 0인 순무, 옥수수, 당근 3종이다. 계절 제한 없이 심는다 |
| K2 | 농기구 업그레이드(`/upgrade can\|bag\|sickle`)를 M2에서 M1로 당긴다. Lv1만으로는 한 칸씩 명령을 쳐야 해서 M1을 해 볼 수 없기 때문이다 |
| K3 | 농기구 Lv2 비용을 500G에서 **200G**로 낮춘다. 시작 골드 100G로 순무 6칸을 한 번 수확하면(220G) 첫 업그레이드에 닿게 한다. Lv3은 5,000G 그대로 |
| K4 | 구매 확인 선택지는 농기구·땅처럼 오래 남는 구매에만 띄운다. 씨앗은 띄우지 않는다 |
| K5 | 로그는 추가될 때 그 시점의 언어로 문구를 만든다. 언어를 바꾸면 새 로그부터 바뀐다 (FR-SET-02) |
| K6 | 게임 이벤트: 작물이 다 자라면 `Ready(구역)`, 자라던 작물의 물이 마르면 `Dry(구역)`를 노란 `●`로 알린다. 한 번의 진행에서 생긴 것을 구역별로 묶는다 |
| K7 | 저장 JSON의 키는 C# 속성 이름 그대로(PascalCase) 쓴다. M1에서 쓰는 필드만 저장하고, 이후 필드는 그 마일스톤에서 더한다 (없으면 기본값) |
| K8 | 테스트 실행 파일은 `Core`, `Data`에 `Storage`까지 묶는다. 저장 왕복을 테스트하기 위해서다 |
| K9 | 개발용 옵션 `--frame [en\|ko]`(예시 상태의 화면 한 장을 글자로 출력)과 `--sprites`(도트 일람)를 둔다 |
| K10 | 창을 닫거나 로그오프할 때(`CTRL_CLOSE_EVENT` 등) 저장한다 |

## 4. 규칙 상세

### 4.1 시간

- 루프마다 실제 경과(UTC)를 `경과 초 × 60 ÷ 배속`으로 게임 분에 더하고, 정수 부분만큼 진행한다. 나머지는 다음 루프로 넘긴다.
- 경과가 5분을 넘으면 꺼져 있던 시간과 같이 처리한다: `min(경과, 상한 2시간)`만 반영하고, 결과를 노란 `● Offline(…)` 이벤트로 남긴다.
- 시작할 때 `지금 − savedAtUtc`를 같은 규칙으로 반영하고, 결과는 시작 환영 상자에 넣는다.
- 성장은 물이 있는 구간만 센다: `성장 += min(물 끝, 진행 끝) − 진행 시작` (다 자라면 멈춤).

### 4.2 농사

| 명령 | 규칙 |
| --- | --- |
| `/plant <작물> <범위>` | 빈 칸에만 심는다. 잠긴 칸, 이미 쓰는 칸은 건너뛰고 개수를 알린다. 씨앗이 모자라면 앞 칸부터 심는다. 이미 젖은 흙에 심으면 물이 그대로 유지된다 |
| `/water <범위>` | 열린 칸 전부에 물(지금부터 24시간). 빈 흙에도 줄 수 있다 |
| `/harvest <범위\|ready>` | 다 자란 칸만 창고로. 창고(40)가 차면 멈추고 남은 칸 수를 알린다. `ready`는 낫 레벨만큼(Lv1 1칸, Lv2 다 자란 칸이 있는 첫 줄, Lv3 구역 전체), 남은 다 자란 칸이 있으면 알린다 |
| `/remove <칸>` | 한 칸만. 작물이 사라진다 |
| `/sell <작물\|all> [개수]` | 기준가 × 개수. 개수를 생략하면 그 작물 전부 |
| 농기구 범위 | 범위가 한 칸이면 Lv1, 한 줄 안이면 Lv2, 그 밖(여러 줄, `all`)은 Lv3이 필요하다 |

### 4.3 상점과 땅

| 항목 | 규칙 |
| --- | --- |
| `/buy seed <작물> [개수]` | 개수 생략 시 1. 1~1,000,000 |
| `/upgrade <can\|bag\|sickle>` | Lv1→2 200G, Lv2→3 5,000G. 최대 Lv3 |
| `/expand [fN] [개수]` | 그 구역의 다음 칸을 산다. 가격은 칸마다 `50 × 10^(n-1) × 1.12^(산 칸 수)` |
| `/expand field` | 새 구역 `20,000 × 10^(n-2)`. `A1`~`A6`이 열려 있고, 산 뒤 그 구역을 보여 준다 |
| 확인 선택지 | 설정 `confirm`이 on이고, 비용이 1,000G 이상이거나 가진 골드의 절반 이상이면 띄운다 (K4) |

### 4.4 화면

- 농장 정보 패널(M1): 구역 이름과 열린 칸, `dry`(물 없는 자라는 작물) / `ready`, `growing` / `empty`, `storage`, `seeds`, `next`(가장 먼저 다 자라는 작물과 남은 실제 시간).
- 스피너 우선순위: 물이 끝나기 전에 다 자라는 작물 → 다 자란 칸 → 물이 필요한 칸 → 대기.
- 시작 환영 상자: 처음이면 시작 방법 3단계, 다시 오면 판·날짜와 부재 중 요약.
