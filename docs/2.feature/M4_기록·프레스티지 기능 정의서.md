# M4_기록·프레스티지 기능 정의서

작성일: 2026-11-27 · 기준 문서: `../1.architecture/wall-geop-lupin 기획·설계서.md`, `01_요구사항 정의서.md`, `02_도메인 모델 및 데이터 포맷.md`, `04_화면 설계.md`, `M3_자동화 기능 정의서.md`

M4 구현 범위와 규칙이다. 설계 문서와 다른 점은 이 문서가 우선하며, 구현 후 개발 명세의 "정의서와 달라진 점"에 남긴다.

## 1. 목표와 범위

엔딩 대신 **지난 기록을 넘어서는 것**을 목표로 만든다. 총자산을 점수로 삼아 체크포인트·일별·판별 기록을 남기고, 프레스티지(Lupin Bloom)로 판을 다시 시작하면 Fertility로 영구 보너스를 산다. 작물 도감과 업적이 쌓인다. 사용자 요청으로 작물별 심는 시기·남은 시간 표(K18~K22), 스프링클러 레벨·범위 표시(K23), 농기구·장비 설명(K24)을 더한다.

| 포함 | 요구사항 |
| --- | --- |
| 총자산, 판 최고 기록 | FR-REC-01, 04 |
| 체크포인트 (Day 7 × 2^k), `NEW BEST` | FR-REC-02 |

| 자라는 작물별 남은 시간 `/growing`, 스프링클러 칸의 남은 시간 계산 (사용자 요청 2026-11-27) | K21, K22 |

## 2. 확정한 결정

| 번호 | 결정 |
| --- | --- |
| K1 | 총자산 = 골드 + 창고 작물 × 지금 단가(판매 압력 없이, 보너스 포함) + 씨앗 × 씨앗값 + 투자액 (D11). 상태·기록·랭킹·프레스티지가 모두 이 값을 쓴다 |
| K2 | 판 최고 기록(최고 총자산과 그때의 게임 날짜)은 명령 뒤, 실시간 진행 뒤, 하루 시작마다(꺼져 있던 동안 포함) 갱신한다 |
| K3 | 체크포인트 Day d(7, 14, 28, 56, …)는 **Day d가 끝나는 순간**(Day d+1 06:00, 시세 갱신 전)의 총자산이다. 꺼져 있던 동안 지나간 체크포인트도 기록한다. 지난 판들의 같은 날 최고 기록보다 크면 `NEW BEST`이고, 지난 기록이 없으면 "첫 기록"이다 |
| K4 | 실제 날짜(로컬 `yyyy-MM-dd`)·판마다 한 줄: 그날 마지막 총자산과 그날 판매 수입(손·규칙 판매 합계). 같은 날 프레스티지를 하면 판마다 따로 남는다. 꺼져 있던 동안의 판매는 다시 켠 날에 들어간다 |
| K5 | 판 기록(`profile.json`의 `Runs`)은 현재 판도 계속 갱신한다: 시작·끝 날짜, 최고 총자산과 날짜, 마지막 날짜, 얻은 Fertility, 체크포인트, 작물별 수확 수. 세이브가 깨져도 남는다 |
| K6 | `/records`: 체크포인트 표(지난 판 최고 · 이번 판 · 차이)와 이번 판 최고·지금 총자산. 행은 Day 7부터 이번 판이나 지난 판이 닿은 마지막 체크포인트까지, 이번 판의 다음 체크포인트 한 줄을 더한다. `/records daily`: 최근 14줄과, 그 밖에 가장 많이 번 날(★)이 있으면 한 줄 더 |
| K7 | `/rank`: 판별 최고 총자산 순위 (최대 20줄). 현재 판은 `(current)` |
| K8 | `/prestige`: 얻을 Fertility = `floor(sqrt(이번 판 최고 총자산 / 100,000))`. 0이면 필요한 금액(100K)과 지금 최고 기록을 알린다. 1 이상이면 상자(이번 판 기록, 얻을 것, 초기화, 유지)와 선택지를 띄우고, 한 번 더 확인한다(기본 선택 No). 구매 확인 설정과 관계없다 |
| K9 | 실행: 판 기록을 마감하고 Fertility를 더한 뒤 새 판(판 번호 + 1, Day 1 봄 06:00)을 만든다. 초기화와 유지는 FR-PRS-05. 시세 난수는 새로 정한다 |
| K10 | 규칙은 문장과 켜짐/꺼짐을 그대로 남기고 실행 횟수·오류를 지운다. 새 판에는 컨트롤러가 없어서 컨트롤러를 사기 전까지는 동작하지 않고, 산 뒤에는 위에서부터 슬롯 수만큼 동작한다 (M3 K7과 같은 규칙) |
| K11 | Lupin Bloom 장면: 농장 영역의 모든 칸에 4프레임(새싹 → 꽃대 → 만개 → 갈아엎음)을 0.7초씩, 2.8초 뒤 새 판 구역 1과 노란 `● Lupin Bloom(run #n)` 이벤트. 장면 중에는 입력을 받지 않는다(보스키는 동작) |
| K12 | 영구 보너스 비용 = 현재 레벨 + 1 Fertility. 확인 선택지 없이 산다. 효과가 바로 붙는 것과 다음 판부터 붙는 것을 `/perks`에 구분해 보여 준다 |
| K13 | 영구 보너스 효과: `rich-soil` 성장 속도 +5%/레벨 (이후 심는 작물부터. 필요한 시간 = 올림(성장 시간 / (1 + 0.05 × 레벨))), `market-sense` 판매 단가 +3%/레벨 (바로), `night-shift` 부재 상한 +2시간/레벨 (바로), `rule-memory` 규칙 슬롯 +1/레벨, 최대 4 (컨트롤러가 있을 때, 바로), `head-start` 시작 골드 +500G/레벨, `old-fields` 구역 1 시작 칸 +2/레벨 최대 12, `seasoned-hands` 농기구 시작 레벨 +1/레벨 최대 2 (마지막 셋은 다음 판부터) |
| K14 | 도감: 작물마다 첫 수확(실제 날짜, 판 번호)과 모든 판의 누적 수확 수. ★ 1개 이상, ★★ 100개 이상, ★★★ 1,000개 이상. 처음 수확하거나 별이 늘면 노란 `● Dex(작물)` 이벤트 |
| K15 | 업적 10종(02 3.8절)은 조건을 처음 만족한 순간 노란 `● Achievement(이름)` 이벤트로 알리고 날짜를 남긴다. `full-auto`는 같은 게임 날 안에 `plant`, `harvest`, `sell` 규칙이 모두 성공한 것, `four-seasons`는 네 계절 작물(그 계절에 심는 작물)을 모든 판을 통틀어 하나 이상씩 수확한 것 |
| K16 | `/status`에 총자산·판 최고·Fertility 줄을 더한다 |
| K17 | 부재 중 요약(시작 환영 상자)에 그동안 지나간 체크포인트를 적는다 |
| K18 | `/crops`: 모든 작물의 계절, 지금 심을 수 있는지(가능하면 제철이 며칠 남았는지, 아니면 며칠 뒤 어느 계절에 되는지), 성장·재수확 일수, 씨앗값·기준가, 잠김 여부를 한 표로 보여 준다. 온실 구역이 있으면 "온실 구역은 계절 상관없음"을 한 줄 더한다 (사용자 요청 2026-11-27) |
| K19 | `/buy seed` 자동완성 후보에 작물 계절과 지금 심을 수 있는지를 적는다. 제철이 아니어서 못 심을 때의 오류에 `/crops` 안내를 붙인다. 계절이 바뀔 때의 이벤트에도 `/crops` 안내를 붙인다 |
| K20 | `/help`의 "예정" 줄을 "기록" 줄(`/records /rank /dex /prestige /perks`)로 바꾸고 `/crops`는 "농사" 줄에 넣는다 |
| K21 | `/growing [fN\|작물]`: 자라는 작물을 구역·작물·상태·남은 시간이 같은 칸끼리 묶어, 다 자람 → 남은 실제 시간이 짧은 순 → 마름 순으로 보여 준다. 다 자란 칸은 `/harvest` 안내(자동 수확 구역이면 "자동 수확기가 거둠"), 다 자라기 전에 물이 끝나는 칸은 물이 끝나는 시간, 마른 칸은 물을 주면 남는 시간을 적는다. 최대 20묶음 (사용자 요청 2026-11-27) |
| K22 | 스프링클러 범위 안의 칸은 매일 06:00에 물을 다시 받으므로, 남은 시간 계산(정보 칸 `다음`, 스피너, `/growing`)에서 물이 끊기지 않는 것으로 본다. 전에는 물이 다음 06:00에 끝나는 것으로 보아 하루보다 오래 걸리는 작물의 시간이 나오지 않았다 |
| K23 | 농장 그림에서 설치한 스프링클러를 알아보게 한다. 스프링클러 칸은 그림 오른쪽 아래에 레벨 숫자(흰색, 밤에도 그대로)를 쓰고, 스프링클러 칸과 물 받는 열린 칸을 합친 영역을 물빛 테두리 하나로 감싼다(바깥 선만, 칸 안은 그대로. 범위가 겹치면 합친다). 범위는 구역 끝에서 잘린다: 구역이 3줄이라 Lv3(사방 2칸)도 최대 14칸. 업그레이드 문구 `now covers n plots`와 `/help place`도 실제로 닿는 칸 수로 적는다 (사용자 요청 2026-11-27) |
| K24 | `/help <이름>`: 농기구(`can` `bag` `sickle`), 창고(`storage`), 장비 8종마다 이름·종류(어떻게 얻는지)·레벨별 가격, 하는 일, 쓰는 법 예시, 지금 상태(레벨, 가진 구역, 보관함·설치 수, 컨트롤러 슬롯·검사 주기, 부재 상한)를 보여 준다. 규칙 장비(자동 수확기·자동 파종기·출하함·자동 구매기)는 컨트롤러가 없으면 "규칙이 동작하지 않음"을 한 줄 더한다. `/help` 첫 화면에 `장비` 줄, `/shop` 끝에 안내 줄, `/help` 자동완성에 이름 후보(`낫 · 농기구`). 수치는 `Content.cs`에서 넣는다 (사용자 요청 2026-11-27) |

## 3. 규칙 상세

### 3.4 저장

| 파일 | 더하는 것 |
| --- | --- |
| `save.json` | 판 최고 총자산·날짜, 체크포인트, 판매 수입 합계, 작물별 수확 수, 보너스 사본, `full-auto` 판정용 값, 칸별 필요 성장 시간 |
