# M3_자동화 기능 정의서

작성일: 2026-11-26 · 기준 문서: `../1.architecture/wall-geop-lupin 기획·설계서.md`, `01_요구사항 정의서.md`, `02_도메인 모델 및 데이터 포맷.md`, `04_화면 설계.md`, `M2_경제 기능 정의서.md`

M3 구현 범위와 규칙이다. 설계 문서와 다른 점은 이 문서가 우선하며, 구현 후 개발 명세의 "정의서와 달라진 점"에 남긴다.

## 1. 목표와 범위

손으로 반복하던 물 주기·수확·심기·판매를 **장비로 열고 규칙으로 조합**해 농장이 혼자 돌아가게 만든다. 꺼져 있던 동안에도 자동화가 일하고, 돌아오면 무엇을 했는지 요약해 준다.

| 포함 | 요구사항 |
| --- | --- |
| 장비 8종 구매 `/buy <장비>` | FR-SHOP-01, 04 |
| 스프링클러 설치·회수·업그레이드 `/place` `/remove` `/upgrade sprinkler` | FR-EQP-01, 02, FR-FARM-10, FR-SHOP-05 |
| 구역 장비(자동 수확기, 자동 파종기, 온실), 농장 장비(출하함, 자동 구매기, 농장 컨트롤러, Caretaker) | FR-EQP-03~06 |
| 규칙 `/auto add|list|on|off|del|move` | FR-AUTO-01~10 |
| 꺼져 있던 동안의 자동화와 부재 중 요약 상세 | FR-TIME-05, 06 |
| 정보 패널의 장비·규칙 줄, `/map` `/inv` `/shop` `/status`의 장비 정보 | FR-FLD-06, 07, FR-SHOP-07 |
| 농장을 접었을 때 안내 줄에 농장 요약 (사용자 요청) | K16 |

| 제외 | 이유 |
| --- | --- |
| 규칙 문장을 프레스티지 뒤에도 남기기 (FR-AUTO-11) | M4 (프레스티지와 함께) |
| Night Shift, Rule Memory 보너스 | M4 |
| 업적 `first-sprinkler` `first-rule` `full-auto` | M4 |

## 2. 확정한 결정

| 번호 | 결정 |
| --- | --- |
| K1 | 장비는 `/buy <장비>`로 산다. 스프링클러는 `/buy sprinkler [개수]`로 사서 장비 보관함에 넣는다. 구역 장비는 `/buy harvester [fN]`처럼 구역을 적고, 생략하면 보는 구역이다. 레벨이 있는 컨트롤러·Caretaker는 `/buy`가 Lv1을 사고, 그 뒤로는 `/upgrade`로 올린다(`/upgrade`는 Lv0에서도 된다) |
| K2 | 장비 비용은 투자액(`Invested`)에 넣는다 (D11). 확인 선택지 규칙(1,000G 이상 또는 골드 절반 이상)을 따른다 |
| K3 | `/place sprinkler <칸>`: 한 칸, 열린 빈 칸(작물·스프링클러 없음)에만. 보관함에서 레벨이 가장 높은 것을 꺼낸다. 놓는 순간과 매일 06:00에 범위 안의 열린 칸에 물을 준다(`물 끝 = max(지금 끝, 지금 + 24시간)`). 범위는 같은 구역 안만 센다 |
| K4 | `/remove <칸>`은 스프링클러를 레벨 그대로 보관함에 돌려준다. `/upgrade sprinkler <칸>`은 설치된 것만 올리고, 올린 즉시 넓어진 범위에 물을 준다 |
| K5 | 엔진은 진행 구간을 **하루 시작(06:00)과 규칙 검사 시각**에서 나눈다. 구간마다 성장 → 경계 이벤트(시세 → 스프링클러 → 계절 → 규칙) 순서다. 꺼져 있던 시간도 같은 방식이라 자동화가 그대로 일한다. "물 마름"은 경계 이벤트 뒤에 판정한다(스프링클러가 바로 다시 주면 마름이 아니다) |
| K6 | 규칙 문법은 02 6.2절을 따르고, 더해서 `stock all`(창고 전체 개수)을 허용한다. `sell all` 뒤에는 개수를 쓰지 않는다(뜻이 모호하다). 연산자는 붙여 써도 된다(`turnip>=35`). 대소문자는 가리지 않고, 저장할 때 소문자·공백 하나로 정리한다 |
| K7 | 슬롯: **켜진 규칙 중 위에서부터 슬롯 수만큼만 동작**하고, 나머지 켜진 규칙은 "슬롯 대기"다. 규칙은 켜진 상태로 추가되고 `/auto on`은 슬롯이 없어도 켠다. 순서는 `/auto move`로 바꾼다. 슬롯 = 컨트롤러 레벨 × 2, 검사 주기는 게임 시간 Lv1 60분, Lv2 30분, Lv3 이상 10분 |
| K8 | 규칙 행동이 무언가를 바꿨을 때만 주황 `● Auto#n(…)` 로그를 남긴다. 조건은 맞았는데 이유가 있어 못 했으면(장비 없음, 구역 없음, 잠긴 작물, 제철 아님, 씨앗 없음, 창고 가득, 골드 부족) 빨간 로그를 남기되 **같은 이유가 이어지는 동안은 한 번만** 남긴다. 성공하면 이유를 지운다. 할 일이 없으면(팔 작물이 없음 등) 조용히 넘어간다 |
| K9 | 같은 규칙이 연달아 실행되면 로그를 한 묶음으로 합친다(제목 `×n`, 수량·금액 합산). 사이에 다른 로그가 끼면 새 묶음이다 |
| K10 | 행동 범위: `harvest`는 구역의 다 자란 칸 전부(낫 레벨 무관), `plant`는 빈 칸 전부(씨앗이 있는 만큼), `sell <작물> <n>`은 최대 n개(재고가 적으면 있는 만큼), 개수 생략은 전부, `buy seed <작물> <n>`은 정확히 n개(골드가 모자라면 사지 않는다) |
| K11 | 구역이 `all`인 행동은 그 장비가 있는 구역마다 실행한다. 장비가 있는 구역이 하나도 없으면 "장비 없음"이다 |
| K12 | 온실 구역은 계절과 상관없이 심고(손·규칙 모두) 재수확한다. 판매가는 그대로라 제철 아닌 작물은 1.3배로 팔린다(온실의 보상) |
| K13 | Caretaker 레벨별 부재 반영 상한: 2·4·8·16·64시간 (02 2.1절) |
| K14 | 부재 중 요약은 지금 상태 기준이다: 지금 다 자란 작물, 지금 마른 칸, 자동화 합계(수확, 심기, 판매 금액, 씨앗 구매), 규칙 오류(최대 3개) |
| K15 | 규칙은 최대 30개까지 둔다. 같은 문장은 두 번 넣지 않는다 |
| K16 | 농장을 접었을 때(`F2`, `/hide`) 맨 아래 안내 줄 오른쪽에 농장 전체 요약을 한 줄로 보여 준다: `Spring 3 14:00 · ready 4 · dry 3 · storage 28/40 · 1,240G · auto 2`. 다 자람은 초록, 마름·창고 가득은 주황 (사용자 요청 2026-11-26) |
| K17 | 정보 패널 아래쪽 세 줄: 스프링클러 수·자동 수확기 / 자동 파종기·온실 / 이 구역에 관련된 동작 중 규칙 번호 |
| K18 | `/auto list` 상태 열 우선순위: 꺼짐 → 슬롯 대기 → 장비 없음 → 마지막 오류 → 실행 횟수 |
| K19 | 규칙은 위에서부터 차례로 실행하고, 앞 규칙의 결과가 뒤 규칙 조건에 바로 반영된다 (예: `harvest` 다음 `stock … do sell`) |
| K20 | 장비로 자동 수확된 작물은 "다 자람" 이벤트를 다시 남기지 않는다: 진행 뒤 그 구역에 다 자란 칸이 남아 있을 때만 `Ready` 로그를 남긴다 |

## 3. 규칙 상세

### 3.1 장비 (02 3.5절)

| ID | 단위 | 비용 | 효과 |
| --- | --- | --- | --- |
| `sprinkler` | 칸 | 500G, Lv2 2,000G, Lv3 10,000G | K3. 범위 Lv1 상하좌우 4칸, Lv2 주변 8칸, Lv3 5×5(24칸. 구역이 3줄이라 실제로는 최대 14칸, M4 K23에서 문구를 바로잡음) |
| `harvester` | 구역 | 3,000G | 규칙 `harvest` |
| `planter` | 구역 | 5,000G | 규칙 `plant` |
| `greenhouse` | 구역 | 50,000G | K12 |
| `shipping-bin` | 농장 | 2,000G | 규칙 `sell` |
| `auto-buyer` | 농장 | 4,000G | 규칙 `buy` |
| `controller` | 농장 | Lv1 1,500G, Lv2 8,000G, Lv3 40,000G, 이후 ×5, 최대 Lv20 | K7 |
| `caretaker` | 농장 | Lv1 1,000G, Lv2 6,000G, Lv3 30,000G, Lv4 150,000G | K13 |

### 3.2 규칙 문법 (02 6.2절 + K6)

```
rule    := "when" cond "do" action
cond    := fieldRef ("ready" | "empty")
         | "price" crop op number
         | "stock" (crop | "all") op number
         | "seed" crop op number
fieldRef:= "f" 숫자 | "all"
op      := ">=" | "<=" | ">" | "<" | "="
action  := "harvest" [fieldRef]
         | "plant" crop [fieldRef]
         | "sell" crop [number] | "sell" "all"
         | "buy" "seed" crop number
```

| 오류 | 알림 |
| --- | --- |
| 기대한 낱말이 아님 | `syntax error at "redy": expected ready | empty` |
| 문장이 일찍 끝남 | `rule ends early: expected …` |
| 행동 뒤에 남은 낱말 | `unexpected "…" after the action` |
| 모르는 작물 | `unknown crop "…"` |
| 조건에 구역이 없는데 `harvest`·`plant`에 구역도 없음 | `harvest needs a field (f1, f2, … or all)` |

### 3.3 명령

| 명령 | 규칙 |
| --- | --- |
| `/buy sprinkler [n]` | 보관함에 n개 |
| `/buy harvester\|planter\|greenhouse [fN]` | 그 구역에 설치. 이미 있으면 오류 |
| `/buy shipping-bin\|auto-buyer` | 농장에 하나. 이미 있으면 오류 |
| `/buy controller\|caretaker` | Lv0이면 Lv1. 이미 있으면 `/upgrade` 안내 |
| `/upgrade sprinkler <칸>` `controller` `caretaker` | 다음 레벨 |
| `/place sprinkler <칸>` | K3 |
| `/remove <칸>` | 작물이면 뽑고, 스프링클러면 보관함으로 |
| `/auto` `/auto list` | 슬롯 사용량, 검사 주기(실제 시간), 규칙 목록 (S14) |
| `/auto add <규칙>` | 문법 검사 후 맨 아래에 켜진 상태로 추가. 지금 동작하는지(슬롯 대기, 장비 없음, 컨트롤러 없음)를 함께 알린다 |
| `/auto on\|off\|del <n>`, `/auto move <n> <m>` | 번호는 목록 순서 |
