# M2_경제 기능 정의서

작성일: 2026-11-26 · 기준 문서: `../1.architecture/wall-geop-lupin 기획·설계서.md`, `01_요구사항 정의서.md`, `02_도메인 모델 및 데이터 포맷.md`, `04_화면 설계.md`, `M1_기반·농사 기능 정의서.md`

M2 구현 범위와 규칙이다. 설계 문서와 다른 점은 이 문서가 우선하며, 구현 후 개발 명세의 "정의서와 달라진 점"에 남긴다.

## 1. 목표와 범위

농사에 **무엇을 언제 심고 언제 팔지** 고르는 재미를 더한다. 작물 10종을 해금하고, 계절마다 심을 수 있는 작물이 바뀌며, 매일 바뀌는 시세와 판매 압력 때문에 나눠 팔고 창고에 쌓아 두는 판단이 생긴다.

| 포함 | 요구사항 |
| --- | --- |
| 작물 10종, 해금 `/unlock` | FR-SHOP-01, 03 |
| 계절: 제철 작물만 심기, 재수확은 제철에만, 계절 바뀜 알림·풀 색 | FR-FARM-02, 08, FR-SEA-01 |
| 밤 표시 | FR-TIME-04 |
| 시세: 매일 변동, 판매 압력, 제철 아님 1.3배, 재현 가능한 난수 | FR-MKT-01~03, 06 |
| `/market` | FR-MKT-05 |
| 창고 업그레이드 `/upgrade storage` | FR-SHOP-05 (창고) |
| `/inv`, `/map` | FR-SHOP-07, FR-FLD-06 |

| 제외 | 이유 |
| --- | --- |
| 온실, 스프링클러 등 장비, 규칙, Caretaker | M3 |
| 기록, 프레스티지, 영구 보너스(판매가 보너스 포함), 도감 | M4 |

## 2. 확정한 결정

| 번호 | 결정 |
| --- | --- |
| K1 | 판매 금액은 1개마다 계수를 0.998배씩 내리는 합을 **등비수열 합 공식**으로 한 번에 계산한다. 1개씩 반올림하지 않고 합계만 반올림한다. 화면에 보이는 단가는 반올림한 값이다. 창고가 아주 커져도(무한 성장) 계산이 빠르다 |
| K2 | 계수는 0.5 아래로 내려가지 않는다. 0.5에 닿은 뒤 파는 것은 0.5 기준이다 |
| K3 | 시세가 바뀔 때마다 로그를 남기지 않는다 (실제 24분마다 생겨서 시끄럽다). `/market`으로 본다 |
| K4 | 계절이 바뀌면 노란 `● Season(…)` 이벤트와 그 계절에 심을 수 있는 작물을 알린다. 한 번의 진행에서 여러 번 바뀌면 마지막 것만 알린다. 꺼져 있던 동안 바뀌었으면 시작 환영 상자에 지금 계절을 적는다 |
| K5 | 재수확 작물은 제철일 때만 다시 열린다. 제철이 아니면 수확 후 빈 칸이 된다 (온실 예외는 M3) |
| K6 | 창고는 최대 Lv20(약 4,194만 개)까지 올린다 |
| K7 | `/plant` 자동완성에는 지금 심을 수 있는(제철) 작물만, `/buy seed`에는 해금한 작물을 모두 보여 준다 (미리 사 둘 수 있게) |
| K8 | 밤(22:00~06:00)에는 농장 영역의 모든 색에 0.55를 곱한다. 헤더 시각은 그대로 |
| K9 | 계절 색은 풀(빈 땅, 잠긴 칸, 칸 사이)만 바꾼다. 흙과 작물 색은 그대로 |
| K10 | 해금 비용은 투자액(`Invested`)에 넣는다 (D11). 해금과 창고 업그레이드도 확인 선택지 규칙(1,000G 이상 또는 골드 절반 이상)을 따른다 |
| K11 | 표 모양 로그(`/market`, `/inv`, `/map`)는 화면 폭 기준으로 칸을 맞춘다. 한국어 작물 이름(2칸 폭)이 섞여도 열이 어긋나지 않게 한다 |
| K12 | 시세 추세(`today`)는 같은 계절 배수에서 어제 계수와 오늘 계수로 만든 단가의 차이다. 계절이 바뀐 날 배수가 변해도 추세에는 나타나지 않는다 |

## 3. 규칙 상세

### 3.1 계절

| 항목 | 규칙 |
| --- | --- |
| 계절 계산 | `((day − 1) / 7) % 4` (M1과 같음) |
| 심기 | 지금 계절이 작물의 계절에 들어 있어야 한다. 아니면 `err.out_of_season`(작물이 자라는 계절과 지금 계절을 알린다) |
| 이미 심은 작물 | 계절이 바뀌어도 끝까지 자란다 (FR-FARM-09) |
| 재수확 | K5 |

### 3.2 시세 (02 3.6절)

| 항목 | 규칙 |
| --- | --- |
| 하루 시작 | 진행 구간 `(t0, t1]` 안의 06:00(게임 분 `% 1440 == 0`)마다 모든 작물의 계수를 바꾼다: `어제 ← f`, `f ← clamp(f + 0.3 × (1 − f) + 0.08 × N(0,1), 0.5, 2.0)` |
| 난수 | xorshift32(상태는 세이브의 `Rng`), 정규분포는 Box–Muller. 작물 순서는 `Content.Crops` 순서로 고정 |
| 단가 | `기준가 × f × (제철이면 1, 아니면 1.3)`를 반올림, 최소 1 |
| 판매 | K1, K2. 판 뒤 계수는 `max(0.5, f × 0.998^개수)` |
| 시작 값 | 모든 작물 `f = 1`, `어제 = 1` |

### 3.3 명령

| 명령 | 규칙 |
| --- | --- |
| `/unlock <작물>` | 해금 비용을 내고 해금한다. 이미 해금했으면 오류 |
| `/upgrade storage` | `400 × 3^레벨`. 용량 2배 |
| `/market` | 해금한 작물: 단가, 기준가, 기준가 대비 %, 어제 대비 추세(▲▼), 제철 아님 표시. 잠긴 작물이 있으면 개수와 `/unlock` 안내 |
| `/inv` | 창고(작물별 수량, 지금 단가, 평가액, 합계), 씨앗 재고 |
| `/map` | 구역별 열린 칸, 다 자람, 마름, 자라는 중, 빈 칸 |
| `/sell` | 결과에 판매 금액, 평균 단가, 판매 전후 단가를 적는다 |
| `/shop` | 씨앗, 해금(잠긴 작물과 비용), 농기구, 창고, 땅 |

## 4. 완료 기준

| 번호 | 기준 |
| --- | --- |
| C1 | `build.bat`, `build.bat test`가 성공한다. 시세 재현성, 판매 압력, 계절 제한, 재수확, 해금, 창고 업그레이드 테스트를 더한다 |
| C2 | `--frame`으로 `/market`, `/inv`, `/map` 표가 영어·한국어 모두 열이 맞는다 |
| C3 | `--sprites`에 작물 10종 모두 전용 도트가 나온다 (대체 그림 없음) |
