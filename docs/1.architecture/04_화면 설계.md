### 3.1 영역

| 영역 | 줄 | 칸 | 내용 |
| --- | --- | --- | --- |
| 헤더 | 0 | 0~119 | 왼쪽 `✻ Lupin Farm`(주황), 오른쪽 `run #n · 계절 n · hh:mm · 골드` |
| 농장 위 테두리 | 1 | | 칸 번호 1~10을 각 칸 가운데 위에 표시 |
| 농장 | 2~13 | | 칸 2: `◀`(가운데 줄), 칸 4: 줄 이름 `A` `B` `C`, 칸 6~85: 도트(밭 10칸 × 8), 칸 88~115: 구역 정보(창 폭 − 32부터), 칸 116: `▶`(창 폭 − 4). M1 구현 기준 (`../3.specification/M1_기반·농사 개발 명세.md` 5.2절) |
| 농장 아래 테두리 | 14 | | 왼쪽 `field n/N`, 가운데 페이지 점 `● ○ ○` (보는 구역 `●`) |
| 로그 | 15 ~ 끝−5 | | 로그 + 맨 아래 스피너 줄 |
| 입력창 | 끝−4 ~ 끝−2 | | 둥근 테두리, `> ` 뒤에 입력. 비어 있으면 회색으로 `Try "/help"`. 한글 자판 글자를 영문 키로 바꿔 넣었으면 위 테두리 오른쪽에 주황 ` Korean keyboard → typed as English keys (한/영) ` (M5 K2) |
| 안내 | 끝−1 | | 왼쪽 `? for shortcuts`, 오른쪽 `PgUp/PgDn field · F2 hide · lang en` |

농장 칸 그림 (M4 K23, 사용자 요청): 스프링클러 칸은 그림 오른쪽 아래에 레벨 숫자(흰색)를 쓴다. 스프링클러 칸과 그 스프링클러가 물을 주는 열린 칸을 합친 영역의 바깥 선을 물빛 1도트 테두리로 긋는다. 선은 칸 흙 가장자리를 따라가고 이웃한 영역 칸 사이 풀 줄에서는 이어진다. 범위가 겹치거나 맞닿으면 테두리 하나로 합친다. Lv1은 십자, Lv2는 3×3, Lv3는 5×3 모양. 범위는 구역 끝에서 잘린다(Lv3 최대 14칸). 입력창에 `/place sprinkler <칸> [레벨]`·`/upgrade sprinkler <칸>`이 칸까지 적혀 있고 놓거나 올릴 수 있으면, 그 뒤의 범위를 밝은 노란 테두리로 덧그린다(지금 범위 위에, M5 K9).

창이 30줄보다 크면 늘어난 줄은 모두 로그 영역에 준다. 창이 120칸보다 넓으면 농장 테두리와 입력창을 창 폭에 맞춰 늘리고, 정보 패널은 오른쪽에 붙인다.

넓은 창 (M5 K3): 창 폭이 204칸 이상이고 구역이 2개 이상이면 구역 그림 2개를 나란히 그린다. 칸 6~85에 왼쪽 구역, 칸 88에 그 줄 이름, 칸 90~169에 오른쪽 구역, 정보 칸은 그대로 창 폭 − 32부터(보는 구역). 보는 구역과 다음 구역을 그리고, 보는 구역이 마지막이면 이전 구역과 마지막 구역이다. 보는 구역은 줄 이름(A~C)과 아래 테두리의 `field n/N`을 주황으로 쓴다. 페이지 점은 정보 칸 아래 가운데로 옮긴다.

```text
┌────────1──── … ──10──────────1──── … ──10────────────────────────────────────┐
│   A ▀▀▀▀▀▀▀ … (field 1, 주황 A~C)   A ▀▀▀▀▀▀▀ … (field 2)     field 1   20/30 plots │
│   B …                               B …                      …                 │
│   C …                               C …                      auto     #1 #3    │
└─ field 1/2 ──────────────────────── field 2/2 ─────────────────────── ● ○ ─────┘
```

### 3.2 구역 정보 패널

| 줄 | 내용 |
| --- | --- |
| 1 | `field n`, 열린 칸 `x/30 plots` (온실이면 `greenhouse` 표시) |
| 3 | `dry` 마른 칸 수(1 이상이면 주황), `ready` 다 자란 칸 수(1 이상이면 초록) |
| 4~5 | 스프링클러 수, 자동 수확기, 자동 파종기, 온실 (있으면 `on`, 없으면 `-`) |
| 7 | 이 구역에 관련된 켜진 규칙 번호 |
| 8 | 가장 먼저 다 자라는 작물과 남은 실제 시간 |

M3 구현: 1 구역·칸, 3 마름·다 자람, 4 자라는 중·빈 칸, 6 창고, 7 씨앗, 8 다음 수확, 10 `sprinkler n` · `harvester on`, 11 `planter -` · `greenhouse -`, 12 `auto #1 #3`(동작 중이고 이 구역을 다루는 규칙, 주황). 장비 값은 이름 뒤에 한 칸 띄워 붙인다.

M5 구현 (K10): 8에 `in box   sprinkler ×n`(보관함에 있는, 아직 놓지 않은 스프링클러. 없으면 흐린 `-`)을 넣고 다음 수확은 9로 내린다. 창고·씨앗 값이 길어도 겹치지 않게 따로 한 줄을 쓴다.

### 3.3 마우스 영역

| 영역 | 동작 |
| --- | --- |
| 농장 줄 2~13, 칸 1~3 | 이전 구역 (`◀`) |
| 농장 줄 2~13, 칸 115~118 | 다음 구역 (`▶`) |
| 아래 테두리의 페이지 점 | 그 구역으로 이동 |
| 도트 영역의 밭 칸 | 좌표(예: `A3`)를 입력창 커서 위치에 넣는다. 앞 글자가 공백이 아니면 공백을 먼저 넣는다. 넓은 창에서 보는 구역이 아닌 그림의 칸은 `f2.A3`처럼 구역을 붙인다 (M5 K3) |
| 로그 영역 휠 | 로그 스크롤 (3줄씩) |

## 4. 로그 형식

| 종류 | 형식 | 예 |
| --- | --- | --- |
| 입력 | 회색 `>` + 명령 | `> /sell turnip` |
| 결과 | 색 `●` + `제목(대상)` | `● Sell(turnip x28)` |
| 세부 | 회색 `  ⎿  ` + 내용. 둘째 줄부터는 `     `로 들여쓴다 | `  ⎿  +1,254G · avg 45G` |
| 스피너 | 주황 `✻` + `Growing…` + 다음 수확 | `✻ Growing… potato B1:B6 ready in 1h 12m` |

- 긴 줄은 화면 폭(한글 2칸)을 넘으면 낱말 사이(공백)에서 줄을 바꾸고 들여쓰기를 맞춘다. 한 낱말이 한 줄보다 길면 글자 단위로 자른다. 줄인 골드 `50.0K G`는 갈라지지 않는다 (M5 K4).
- 한 줄 안의 값은 뜻에 따라 색을 나눈다 (M5 K5): 오름·좋음 초록, 내림·나쁨 빨강, 주의 주황. 시작 상자와 선택지는 한 색 그대로.
- 스피너 글자는 `✻` `✶` `✳` `✢`를 1초마다 돌린다. 자라는 작물이 없으면 `✻ Idle · /plant to start`를 보여 준다.
- 한국어 모드 예: `● 수확(구역 1)` / `  ⎿  순무 4개 → 창고 28/40`

## 6. S03 자동완성 목록

```text
╭──────────────────────────────────────────────────────────────────────────────╮
│ > /up                                                                        │
╰──────────────────────────────────────────────────────────────────────────────╯
  ❯ /upgrade can          watering can Lv1 → Lv2       200G
    /upgrade bag          seed bag Lv1 → Lv2           200G
    /upgrade sickle       sickle Lv1 → Lv2             200G
    /upgrade storage      storage 40 → 80              400G
    /upgrade caretaker    offline cap 2h → 4h        1,000G
```

- 최대 6줄. 목록이 열리면 로그 영역이 그만큼 줄고, 입력창이 위로 올라가며 목록이 안내 줄 자리부터 아래로 펼쳐진다.
- 후보: 명령어 → 하위 명령 → 작물·아이템·구역 이름 순서로, 지금 입력한 단어에 맞춘다.
- `↑` `↓` 이동, `Tab`/`Enter` 채우기, `Esc` 닫기. 고른 항목의 오른쪽에는 설명과 가격(있으면)을 보여 준다.

## 7. S04 선택지

```text
╭────────────────────────────────────────────────────────────╮
│ Buy controller for 1,000G?  (gold 1,240G → 240G)           │
│                                                            │
│ ❯ 1. Yes                                                   │
│   2. No                                                    │
│                                                            │
│ Enter to select · ↑↓ or 1-2 · Esc to cancel                │
╰────────────────────────────────────────────────────────────╯
```

- 로그 영역 맨 아래(입력창 바로 위)에 뜬다. 입력창은 회색으로 비활성.
- 숫자 키를 누르면 바로 고른다. `Esc`는 마지막 선택지(No)와 같다.
- 두 번 확인하는 경우(프레스티지, 초기화)는 두 번째 상자의 기본 선택을 No로 둔다.

## 8. S05 농장 접기

헤더와 농장 영역이 사라지고 로그와 입력창만 남는다. AI 코딩 도구 세션처럼 보인다.

```text
> /harvest A1:A4
● Harvest(field 1)
  ⎿  turnip x4 → storage 28/40
> /sell turnip
● Sell(turnip x28)
  ⎿  +1,254G · avg 45G · price 46G → 43G ▼
✻ Growing… potato B1:B6 ready in 1h 12m
╭──────────────────────────────────────────────────────────────────────────────╮
│ >                                                                            │
╰──────────────────────────────────────────────────────────────────────────────╯
  ? for shortcuts
```

- 안내 줄 오른쪽 표시(`PgUp/PgDn field …`) 대신 농장 전체 요약을 한 줄로 보여 준다 (FR-UI-11, M3 K16): `Spring 4 14:00 · ready 2 · dry 12 · storage 28/40 · 1,240G · auto 3`. 다 자람 초록, 마름·창고 가득 주황, 나머지 회색. 컨트롤러가 없으면 `auto`는 빠진다.
- `/hide` 또는 `F2`를 다시 누르면 펼친다. 접힌 상태는 프로필에 저장하지 않는다 (다음 실행은 펼친 상태).

## 9. S06 보스 모드

대체 화면에서 나와, 시작할 때 찍어 둔 프롬프트만 보인다. 커서는 프롬프트 뒤에 있다.

```text
PS C:\dev\git\my>
```

- 화면 출력을 멈추고, 보스키 외의 입력은 무시한다.

### S15 기록 `/records`

```text
> /records
● Records(run #3 · Day 31)
  ⎿  Day    Best           Run #3     Diff
```

```text

  ⎿  folder   C:\Users\me\AppData\Local\LupinFarm
     saved    16:10:05 · every 30s, after each command, on exit
     exports  2 in export\ · latest lupin-20261127-161002.json (2026-11-27 16:10)

  ⎿  written to C:\Users\me\AppData\Local\LupinFarm\export\lupin-20261127-161002.json

```

`/save import <file>`은 파일을 읽어 확인한 뒤 선택지를 띄운다(기본 `No`).

```text
╭──────────────────────────────────────────────────────────────────────────────────────────╮
│ Import lupin-20261127-161002.json?                                                       │
│                                                                                          │
│   file   run #1 · Day 102 · net worth 61.7K · run records: 1 · exported 2026-11-27 16:10 │
│   now    run #1 · Day 2 · net worth 100 · run records: 1                                 │
│   your current data is exported first, so you can import it back                         │
│                                                                                          │
│   1. Import                                                                              │
│ ❯ 2. No                                                                                  │
│                                                                                          │
│ Enter to select · ↑↓ or 1-2 · Esc to cancel                                              │
╰──────────────────────────────────────────────────────────────────────────────────────────╯
```

- 가져오면 `● Save import`에 가져온 파일, 판 요약, 이전 데이터 파일(`export\before-import-…`)을 적고, 내보낸 뒤 지난 시간이 있으면 부재 중 요약 이벤트가 이어진다.
- 상대 경로와 이름만 적은 파일은 `export` 폴더 기준이다. 현재 폴더에는 쓰지 않는다. `/save import ` 자동완성은 `export` 폴더의 파일(최근 순, `exported 2026-11-27 16:10`).
- 파일이 없거나, Lupin Farm 파일이 아니거나, 새 버전 파일이거나, 깨졌으면 빨간 `●`로 이유를 알리고 지금 데이터는 그대로다.
