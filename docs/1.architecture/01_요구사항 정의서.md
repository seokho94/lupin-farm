# 01. 요구사항 정의서

작성일: 2026-11-26 · 기준 문서: `wall-geop-lupin 기획·설계서.md`

MVP 요구사항이다. ID는 기능 정의서, 개발 명세, 테스트에서 참조한다. 시간 단위는 별도 표시가 없으면 **게임 시간**이다 (실제 시간 ÷ 배속). 수치는 `02_도메인 모델 및 데이터 포맷.md`의 초기값을 따른다.

## 1. 역할

| 역할 | 설명 |
| --- | --- |
| 사용자 | 회사 PC 사용자 1명. 모든 기능을 쓴다 |

## 2. 기능 요구사항

### 2.1 화면 (F1)

| ID | 요구사항 |
| --- | --- |
| FR-UI-01 | 화면은 위에서부터 헤더(1줄), 농장 영역(14줄), 로그 영역(남는 줄), 입력창(3줄), 안내 줄(1줄)로 나눈다 |
| FR-UI-02 | 최소 창 크기는 120×30이다. 더 작으면 크기 안내만 보여 주고, 게임 시간은 계속 흐른다 |
| FR-UI-03 | 농장 영역은 반쪽 블록 문자(`▀`)와 24비트 색으로 도트를 그린다. 밭 한 칸은 8×8 픽셀이다 |
| FR-UI-04 | 화면은 바뀐 칸만 다시 그린다. 깜빡임이 없어야 한다 |
| FR-UI-05 | 명령 결과는 로그에 `●` 제목 줄과 `⎿` 세부 줄로 남긴다. 색은 성공 초록, 오류 빨강, 자동화 주황, 이벤트 노랑이다 |
| FR-UI-06 | 로그 맨 아래에 `✻` 스피너 줄로 가장 먼저 다 자라는 작물과 남은 실제 시간을 보여 준다. 스피너는 1초마다 바뀐다 |
| FR-UI-07 | 로그는 최근 500건을 메모리에 둔다. 마우스 휠과 `Shift+PgUp`/`Shift+PgDn`으로 스크롤한다. 새 로그가 생기면 맨 아래로 돌아간다 |
| FR-UI-08 | 실행하면 로그 맨 위에 시작 환영 상자(게임 이름, 판 번호, 날짜, 부재 중 요약)를 보여 준다 |
| FR-UI-09 | 농장 영역을 뺀 글자는 터미널 기본 배경색을 그대로 쓴다 |
| FR-UI-10 | 헤더 왼쪽에 게임 이름, 오른쪽에 판 번호·계절·날짜·시각·골드를 보여 준다 |
| FR-UI-11 | 농장을 접었을 때 안내 줄 오른쪽에 농장 전체 요약(계절·날짜·시각, 다 자란 칸, 마른 칸, 창고, 골드, 동작 중 규칙)을 보여 준다 (사용자 요청 2026-11-26, M3 K16) |

### 2.2 입력과 명령 (F2)

| ID | 요구사항 |
| --- | --- |
| FR-CMD-01 | 입력창에서 글자 입력, `Backspace`, `Delete`, `←` `→`, `Home` `End`로 편집한다 |
| FR-CMD-02 | `Enter`로 실행한다. 명령은 `/`로 시작하고, 대소문자를 구분하지 않는다 |
| FR-CMD-03 | `↑` `↓`로 이전 명령을 불러온다. 최근 100개를 프로필에 저장한다 |
| FR-CMD-04 | `/`를 입력하면 자동완성 목록(최대 6줄)이 입력창 아래에 펼쳐진다. `Tab`은 명령어, 하위 명령, 작물·아이템·구역 이름을 채운다. 목록이 열려 있으면 `↑` `↓`는 목록을 움직인다 |
| FR-CMD-05 | 알 수 없는 명령이나 잘못된 인자는 빨간 `●`와 사용법 한 줄로 알린다. 상태는 바뀌지 않는다 |
| FR-CMD-06 | 밭 범위는 `A1`, `A1:A4`, `A1:C3`(사각형), `A`(한 줄), `all`(구역 전체)로 쓴다. 다른 구역은 `f2.A1:A4`처럼 접두사를 붙인다. 접두사가 없으면 지금 보고 있는 구역이다 |
| FR-CMD-07 | 1,000G 이상이거나 가진 골드의 절반 이상을 쓰는 구매는 번호 선택지로 확인한다. 설정으로 끌 수 있다. 프레스티지와 초기화는 끌 수 없다 |
| FR-CMD-08 | `Ctrl+C`: 입력이 있으면 지운다. 비어 있으면 "한 번 더 누르면 종료" 안내를 띄우고, 2초 안에 다시 누르면 저장 후 종료한다. `/exit`도 저장 후 종료한다 |
| FR-CMD-09 | `Esc`: 자동완성 목록 닫기 → 입력 지우기 → 선택지 취소 순서로 동작한다 |
| FR-CMD-10 | 명령어와 인자는 언어 설정과 상관없이 영어다 |

### 2.3 시간 (F3)

| ID | 요구사항 |
| --- | --- |
| FR-TIME-01 | 게임 시간은 실제 경과 시간을 배속(게임 1시간당 실제 초, 기본 60초)으로 나눠 흐른다 |
| FR-TIME-02 | 하루는 06:00에 시작한다. 새 판은 Day 1 봄 1일 06:00에 시작한다 |
| FR-TIME-03 | 계절은 7일씩, 봄 → 여름 → 가을 → 겨울 순서로 반복한다 |
| FR-TIME-04 | 22:00~06:00은 밤이다. 농장 영역을 어둡게 칠한다 (표시만 바뀐다) |
| FR-TIME-05 | 꺼져 있던 시간은 실제 시간 기준 상한까지만 반영한다. 기본 상한은 2시간이고, Caretaker와 Night Shift로 늘어난다 |
| FR-TIME-06 | 꺼져 있던 시간을 반영하는 동안에는 자동화(스프링클러, 규칙)만 동작한다. 결과는 시작 환영 상자에 요약한다 |
| FR-TIME-07 | 앱이 켜져 있는 동안은 화면 잠금, 보스 모드, 농장 접기와 관계없이 시간이 흐른다 |
| FR-TIME-08 | 루프 사이 실제 경과가 5분을 넘으면(PC 절전 등) 꺼져 있던 시간과 같은 규칙으로 처리한다 |
| FR-TIME-09 | PC 시계가 저장 시각보다 이르면 경과 시간을 0으로 본다 |

### 2.4 농사 (F4)

| ID | 요구사항 |
| --- | --- |
| FR-FARM-01 | `/plant <작물> <범위>`: 범위 안 빈 칸에 씨앗을 1개씩 심는다. 씨앗이 모자라면 앞 칸부터 가능한 만큼 심고 결과에 적는다 |
| FR-FARM-02 | 제철 작물만 심을 수 있다. 온실 구역은 예외다 |
| FR-FARM-03 | `/water <범위>`: 물은 준 시점부터 24시간 유지된다 |
| FR-FARM-04 | 작물은 물이 있는 동안만 자란다. 물이 없어도 시들지 않는다 |
| FR-FARM-05 | 자라는 단계는 씨앗(0~25%), 새싹(25~60%), 자라는 중(60~100%), 다 자람(100%)이다 |
| FR-FARM-06 | 다 자란 작물은 수확할 때까지 그대로 있다 |
| FR-FARM-07 | `/harvest <범위\|ready>`: 다 자란 작물을 창고에 넣는다. 창고가 차면 남은 칸은 그대로 두고 알린다 |
| FR-FARM-08 | 재수확 작물은 수확 후 새싹 단계로 돌아가 재수확 기간 뒤 다시 다 자란다. 제철(또는 온실)이 아니면 수확 후 빈 칸이 된다 |
| FR-FARM-09 | 이미 심은 작물은 계절이 바뀌어도 끝까지 자란다 |
| FR-FARM-10 | `/remove <칸>`: 작물을 뽑거나(사라진다) 설치한 스프링클러를 회수한다(장비 보관함으로) |
| FR-FARM-11 | 범위가 농기구 레벨로 처리할 수 있는 크기보다 크면 실행하지 않고 필요한 레벨을 알린다 |
| FR-FARM-12 | `/crops`: 작물마다 계절, 지금 심을 수 있는지(제철이 며칠 남았는지) 또는 며칠 뒤 어느 계절에 되는지, 성장·재수확 일수, 값, 잠김 여부를 보여 준다. 씨앗 구매 자동완성에도 계절을 적는다 (사용자 요청 2026-11-27, M4 K18·K19) |
| FR-FARM-13 | `/growing [fN\|작물]`: 자라는 작물을 묶어 다 자랄 때까지 남은 실제 시간 순으로 보여 준다. 스프링클러 범위 안의 칸은 물이 끊기지 않는 것으로 계산한다 (사용자 요청 2026-11-27, M4 K21·K22) |

### 2.5 구역과 페이지 (F5)

| ID | 요구사항 |
| --- | --- |
| FR-FLD-01 | 구역은 밭 10칸 × 3줄이다. 줄은 `A`~`C`, 칸은 `1`~`10`이다 |
| FR-FLD-02 | 새 판은 구역 1의 `A1`~`A6`이 열린 채로 시작한다 |
| FR-FLD-03 | `/expand [구역] [개수]`: 그 구역의 다음 칸을 산다 (A1→A10→B1→…→C10 순서). `/expand field`: 새 구역을 산다. 새 구역은 `A1`~`A6`이 열려 있다 |
| FR-FLD-04 | 보는 구역은 `/field <n\|next\|prev>`, `PgUp`/`PgDn`, 농장 영역 양옆 `◀` `▶` 클릭, 페이지 점 클릭으로 바꾼다 |
| FR-FLD-05 | 밭을 클릭하면 그 좌표(예: `A3`)를 입력창 커서 위치에 넣는다 |
| FR-FLD-06 | `/map`: 전체 구역 요약표(열린 칸, 다 자람, 마름, 자라는 중, 장비)를 로그에 보여 준다 |
| FR-FLD-07 | 농장 영역 오른쪽에 보는 구역의 정보(열린 칸, 마른 칸, 다 자란 칸, 장비, 규칙, 다음 수확)를 보여 준다 |

### 2.6 상점, 농기구, 작물 해금 (F6)

| ID | 요구사항 |
| --- | --- |
| FR-SHOP-01 | `/shop`: 살 수 있는 것(씨앗, 작물 해금, 농기구, 장비, 창고, 땅)과 가격을 보여 준다 |
| FR-SHOP-02 | `/buy seed <작물> <개수>`: 해금한 작물의 씨앗을 산다 |
| FR-SHOP-03 | `/unlock <작물>`: 작물을 해금한다. 한 번만 산다 |
| FR-SHOP-04 | `/buy <장비> [구역]`: 장비를 산다. 구역 단위 장비는 구역을 적는다 (기본: 보는 구역) |
| FR-SHOP-05 | `/upgrade <can\|bag\|sickle\|storage\|caretaker\|controller>`, `/upgrade sprinkler <칸>`: 다음 레벨로 올린다 |
| FR-SHOP-06 | 농기구 레벨별 범위: Lv1 한 칸, Lv2 한 줄 안의 범위, Lv3 구역 안의 모든 범위 |
| FR-SHOP-07 | `/inv`: 창고(작물별 수량, 용량)와 씨앗 재고, 장비 보관함을 보여 준다 |
| FR-SHOP-08 | 골드가 모자라면 부족한 금액을 알린다 |

### 2.7 시세와 계절 (F7)

| ID | 요구사항 |
| --- | --- |
| FR-MKT-01 | 매일 06:00에 작물마다 시세가 바뀐다. 시간이 지나면 기준가로 돌아오는 무작위 변동이다 |
| FR-MKT-02 | 한 개를 팔 때마다 그 작물의 시세가 조금씩 내려간다 (판매 압력). 한 번에 많이 팔수록 평균 단가가 낮다 |
| FR-MKT-03 | 제철이 아닌 작물은 시세에 1.3배를 곱한다 |
| FR-MKT-04 | `/sell <작물\|all> [개수]`: 창고의 작물을 판다. 출하함이 없어도 손으로 팔 수 있다 |
| FR-MKT-05 | `/market`: 작물별 현재가, 기준가, 기준가 대비 %, 어제 대비 추세(▲▼), 제철 여부를 보여 준다 |
| FR-MKT-06 | 시세 난수는 세이브에 저장된 난수 상태로 만든다. 같은 상태와 같은 입력이면 같은 결과가 나온다 |
| FR-SEA-01 | 계절이 바뀌면 로그에 알리고 농장의 풀·흙 색을 바꾼다 |

### 2.8 자동화 장비 (F8)

| ID | 요구사항 |
| --- | --- |
| FR-EQP-01 | `/place sprinkler <칸>`: 장비 보관함의 스프링클러를 빈 칸에 설치한다. 그 칸에는 심을 수 없다 |
| FR-EQP-02 | 스프링클러는 설치할 때와 매일 06:00에 범위 안 밭에 물을 준다. 범위는 Lv1 상하좌우 4칸, Lv2 주변 8칸, Lv3 5×5이다. 구역이 3줄이라 Lv3도 실제로 닿는 칸은 최대 14칸이다. 농장 그림에 스프링클러 레벨 숫자와 범위(스프링클러와 물 받는 칸을 감싼 파란 테두리)를 표시한다 (사용자 요청 2026-11-27, M4 K23) |
| FR-EQP-03 | 자동 수확기, 자동 파종기, 온실은 구역마다 하나씩 설치한다 |
| FR-EQP-04 | 출하함, 자동 구매기, 농장 컨트롤러, Caretaker는 농장 전체에 하나다 |
| FR-EQP-05 | 온실 구역은 계절 제한 없이 심고 재수확한다 |
| FR-EQP-06 | Caretaker 레벨에 따라 꺼져 있던 시간의 반영 상한이 늘어난다 |
| FR-EQP-07 | `/help <이름>`으로 농기구·창고·장비마다 종류, 가격, 하는 일, 쓰는 법 예시, 지금 상태를 보여 준다. 규칙이 필요한 장비는 컨트롤러가 없으면 알린다. `/help` 첫 화면과 `/shop`에 안내 줄을 둔다 (사용자 요청 2026-11-27, M4 K24) |

### 2.9 자동화 규칙 (F9)

| ID | 요구사항 |
| --- | --- |
| FR-AUTO-01 | `/auto add when <조건> do <행동>`으로 규칙을 추가한다 |
| FR-AUTO-02 | 조건: `<구역> ready`, `<구역> empty`, `price <작물> <비교> <수>`, `stock <작물|all> <비교> <수>`, `seed <작물> <비교> <수>`. 구역은 `f1`, `f2`, … 또는 `all`. 비교는 `>=` `<=` `>` `<` `=` (`stock all`은 M3 K6) |
| FR-AUTO-03 | 행동: `harvest [구역]`, `plant <작물> [구역]`, `sell <작물\|all> [개수]`, `buy seed <작물> <개수>`. 구역을 생략하면 조건의 구역이다 |
| FR-AUTO-04 | 행동을 쓰려면 장비가 있어야 한다: `harvest` 자동 수확기, `plant` 자동 파종기, `sell` 출하함, `buy` 자동 구매기. 없으면 실행하지 않고 목록에 "needs …"로 표시한다 |
| FR-AUTO-05 | 규칙은 농장 컨트롤러의 검사 주기마다 위에서부터 검사하고, 조건이 맞으면 행동을 1회 실행한다 |
| FR-AUTO-06 | 동작하는 규칙 수는 컨트롤러 슬롯 수까지다. 켜진 규칙 중 위에서부터 슬롯 수만큼 동작하고 나머지는 슬롯 대기다 (M3 K7). 컨트롤러가 없으면 규칙이 동작하지 않는다 |
| FR-AUTO-07 | `/auto list`, `/auto on <n>`, `/auto off <n>`, `/auto del <n>`, `/auto move <n> <m>` |
| FR-AUTO-08 | 실행 결과는 바뀐 것이 있을 때만 로그에 남긴다. 같은 규칙이 연달아 실행되면 한 줄로 묶는다 (`×n`) |
| FR-AUTO-09 | 문법이 틀린 규칙은 추가하지 않고 틀린 위치를 알린다 |
| FR-AUTO-10 | 규칙 행동은 손으로 하는 명령과 같은 제약(씨앗, 창고, 계절, 골드)을 따른다. 농기구 레벨 제한은 받지 않는다 |
| FR-AUTO-11 | 규칙 문장은 프레스티지 후에도 남는다. 켜짐/꺼짐도 그대로 남고, 컨트롤러를 산 뒤 위에서부터 슬롯 수만큼 동작한다 (M3 K7, M4 K10) |

### 2.10 기록과 랭킹 (F10)
