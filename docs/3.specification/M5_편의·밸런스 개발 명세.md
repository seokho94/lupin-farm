## 3. 저장 형식

`save.json`·`profile.json`은 바뀌지 않는다. 새 파일은 내보내기 파일(`export\*.json`)이다: `{ Format: "lupin-farm-export", Version: 1, ExportedAt, Save, Profile }` (`../1.architecture/02_도메인 모델 및 데이터 포맷.md` 5.1절). 사용자 세이브 복사본으로 만든 파일은 12KB였다.

## 4. 밸런스 (K12)

### 4.1 시뮬레이션

`bin\tests.exe balance [일수] [추적 간격]`. `BalanceSim`은 정해진 간격(게임 6시간·하루·이틀)마다 들여다보는 플레이어가 `Commands.Execute`만으로 다음을 한다. 한 번 들여다볼 때 명령은 15개까지다(농기구 레벨이 손을 덜어 주는 효과가 드러나게).

1. 창고 판매, 다 자란 칸 수확(`/harvest fN.ready`, 낫 레벨만큼), 판매.
2. 구매: 농기구 Lv2 → 스프링클러(B2·B5·B8, 빈 칸일 때) → 더 나은 제철 작물 해금 → 자동화(컨트롤러 + 자동 수확기 + 출하함 + 규칙 2개) → 칸(회수 기간 90일 안) → 창고 → 살 만한 칸을 다 샀으면 새 구역 → 다른 구역 자동 수확기(슬롯이 모자라면 컨트롤러 Lv2) → 사치품(농기구 Lv3, 스프링클러 Lv2: 다음 구역 값의 절반 이상 여유가 있을 때).
3. 빈 칸에 하루당 이익이 가장 높은 제철 작물을 사서 심고(씨앗 주머니 레벨만큼), 다음에 들여다보기 전에 마를 칸에 물을 준다.

다시 심을 씨앗값은 남겨 둔다. 기록하는 단계: 농기구 Lv2(`tool2`), 스프링클러(`sprinkler`), 컨트롤러 + 자동 수확기(`auto`), 구역 2(`field2`), 총자산 100K·1M. 명령 수 한도를 40으로 늘려도 결과가 거의 같아서(1M 242일 → 231일), 진행은 손이 아니라 돈이 정한다 (개발 이슈 5).

바꾸지 않은 것: 농기구(200G·5,000G), 창고, 자동 파종기·온실·자동 구매기, 스프링클러 업그레이드, 컨트롤러 Lv2 이상, Caretaker, 시세 변동·판매 압력·제철 배수, 프레스티지(Fertility 식, 보너스 — M4 U7에서 확인), 시작 골드·칸, 기본 배속(사용자 결정).

## 5. 명령 (M5에서 추가·변경)

| 명령 | 내용 |
| --- | --- |
| `/save` | 저장 폴더, 마지막 저장 시각, `export` 폴더의 파일 수·가장 최근 파일, 쓰는 법 |
| `/save export [파일\|폴더]` | 저장한 뒤 판·프로필을 파일 하나로. 기본 `export\lupin-yyyyMMdd-HHmmss.json`. 상대 경로는 export 폴더 기준, 확장자가 없으면 `.json`, 폴더면 그 안에 기본 이름. 이미 있으면 바꾸고 알린다 |
| `/save import <파일>` | 읽고 확인 → 선택지(가져올 판·지금 판 요약, 기본 No) → 지금 데이터 `before-import-…` 내보내기(실패하면 중단) → 바꾸기 → 내보낸 뒤 1분 넘게 지났으면 부재 중 요약 |
| `/place sprinkler <칸> [레벨]` | 레벨 고르기 (`2`, `lv2`). 없으면 가장 높은 레벨 |
| 한글 자판으로 친 명령 | 모든 명령이 영문 키로 바뀐 뒤 실행된다 (`/save` 경로 제외) |
