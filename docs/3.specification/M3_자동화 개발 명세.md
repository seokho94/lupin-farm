## 3. 저장 형식

`save.json`에 필드가 생겼다. M2 세이브를 불러오면 `Normalize()`가 빈 값으로 채운다 (장비 없음, 규칙 없음).

```json
"EquipmentBox": { "sprinkler1": 1 },
"Farm": { "ShippingBin": true, "AutoBuyer": false, "Controller": 2, "Caretaker": 1 },
"Rules": [ { "Text": "when f1 ready do harvest", "On": true, "Runs": 12, "Fail": null } ],
"Fields": [ { "Open": 20, "Bought": 14, "Harvester": true, "Planter": false, "Greenhouse": false,
              "Plots": [ { "Crop": null, "Growth": 0, "WaterUntil": 4320, "Harvests": 0, "Sprinkler": 2 } ] } ]
```

- `Rules[].Text`는 정리된 문장이다. 불러올 때 다시 해석한다(캐시).
- `Rules[].Fail`은 마지막으로 못 한 이유(`needs` `no_field` `locked` `season` `no_seed` `storage_full` `no_gold`)다. 같은 이유는 한 번만 알리는 데 쓴다.

## 4. 장비와 규칙 요약

| 장비 | 구현 |
| --- | --- |
| 스프링클러 | `/buy sprinkler [n]` → 보관함(`sprinkler1`). `/place`가 가장 높은 레벨을 꺼내 놓고 바로 물. 매일 06:00 `Farming.SprinklerDay`. 범위는 같은 구역의 열린 칸, 물 끝 = `max(지금 끝, 지금 + 1440)`. 스프링클러 칸은 심기·빈 칸 수에서 빠진다 |
| 구역 장비 | `FieldState.Harvester/Planter/Greenhouse`. 온실은 `Farming.SeasonOk`가 늘 참 (손 `/plant`, 규칙 `plant`, 재수확) |
| 농장 장비 | `FarmEquipment`. 컨트롤러 슬롯 `레벨 × 2`, 주기 60/30/10분. Caretaker 상한 2/4/8/16/64시간 |

| 규칙 | 구현 |
| --- | --- |
| 해석 | `Rules.Tokenize`(공백·비교 연산자 분리, 소문자) → 한 번에 읽는 해석기. 틀리면 `rule.err.at`(낱말, 기대한 것), `rule.err.end`, `rule.err.extra`, `rule.err.crop`, `rule.err.field` |
| 동작 범위 | `Rules.Active`: 켜진 규칙 중 위에서부터 슬롯 수만큼 |
| 실행 | `Rules.Run`: 동작 중 규칙마다 조건 → 장비 확인(`Missing`) → 행동. 성공이면 `Runs++`, `Fail` 지움. 못 했으면 이유가 바뀔 때만 기록 |
| 로그 | 성공 `● Auto#n(행동)` 주황, 못 함 빨강. 한 진행 안에서 같은 규칙은 `AdvanceReport.AddRun`이, 진행 사이에서는 `App.AddRun`이 바로 앞 묶음과 합친다(`×n`) |

## 5. 엔진 진행 (`Engine.Advance`)

```
while 지금 < 끝:
  t1 = min(끝, 다음 06:00)
  규칙 검사가 있으면:
    바뀐 것이 있었으면  t1 = min(t1, 다음 검사 시각)
    없었으면            t1 = min(t1, 다음에 다 자라는 칸 뒤의 첫 검사 시각)
  성장(t0, t1]  → 새로 다 자란 칸이 있으면 "바뀜"
  t1이 06:00이면 시세 → 스프링클러 → 계절, "바뀜"
  t1이 검사 시각이고 "바뀜"이면 규칙 실행 (농장을 바꾼 규칙이 있을 때만 "바뀜" 유지)
  이 구간에 물이 끝난 칸 중 지금도 마른 칸만 "물 마름"
```

- 꺼져 있던 시간, 절전 복귀, 실시간 진행 모두 같은 함수다. 그래서 꺼져 있던 동안에도 스프링클러와 규칙이 일한다.
- 검사를 건너뛰어도 결과가 같다는 것을 `TestBigStepEqualsSmallSteps`(12일을 한 번에 / 10분씩 1,728번)로 확인한다.
- 최악(Caretaker Lv4 64시간, 배속 5 → 게임 1,920일, 구역 30개 전자동 온실): 약 0.6초. 최적화 전 4.2초 (개발 이슈 4).

## 6. 명령 (M3에서 추가·변경)

| 명령 | 결과 예 |
| --- | --- |
| `/buy sprinkler 2` | `● Buy(sprinkler x2)` `⎿ +2 sprinkler · 2 in the box · -1,000G · gold …` + `/place` 안내 |
| `/buy harvester f2` | `● Buy(harvester · field 2)` `⎿ -3,000G · gold …` + 규칙 예시 |
| `/buy controller` | Lv0이면 Lv1 구매 (`/upgrade controller`와 같음). 있으면 `/upgrade` 안내 |
| `/place sprinkler B3` | `● Place(field 1)` `⎿ sprinkler Lv1 at B3 · watered 4 plots` `waters every day at 06:00 · 1 left in the box` |
| `/upgrade sprinkler B3` | `⎿ Lv1 → Lv2 · -2,000G` `now covers 8 plots · watered 8 just now` |
| `/remove B3` | 스프링클러면 `sprinkler Lv2 taken from B3 · 1 in the box` |
| `/auto add when f1 ready do harvest` | `● Auto(add #1)` `⎿ #1 when f1 ready do harvest` + 동작 여부 (동작 중 / 슬롯 대기 / 장비 필요 / 컨트롤러 없음) |
| `/auto list` | `● Auto(3/4 slots · checks every 30s)` + `#n 상태 문장 비고` 표 |
| `/auto on\|off\|del <n>`, `/auto move <n> <m>` | 번호·문장과 안내 |
| `/status` | 마지막 줄 `auto 3/4 slots in use · 4 rules · checks every 30s` |
| `/inv` `/map` `/shop` | 장비 줄·열 추가 (`gear`, `field gear`, `farm gear`) |

### 6.1 열 폭

| 표 | 열 (폭) |
| --- | --- |
| `/auto list` | 번호 5 · 상태 6 · 문장(가장 긴 문장 + 3, 최대 63) · 비고 |
| `/map` | field 8 · plots 9 · ready 8 · dry 7 · growing 10 · empty 8 · gear |

### 6.2 화면

- 정보 패널(창 폭 − 32부터) 9~11번째 줄: `sprinkler n` / `harvester on`, `planter -` / `greenhouse -`, `auto #1 #3`(이 구역에 관련된 동작 중 규칙, 주황). 이름 길이에 맞춰 값이 붙어 한국어 `스프링클러 1`도 열 안에 들어간다.
- 접은 화면(K16): 안내 줄 오른쪽에 `Spring 4 14:00 · ready 2 · dry 12 · storage 28/40 · 1,240G · auto 3`. 다 자람 초록, 마름·창고 가득 주황, 나머지 회색. 컨트롤러가 없으면 `auto`는 빠진다.
- 부재 중 요약: `auto harvested …` `auto planted …` `auto sold … → +…` `auto bought seeds … · -…` `Auto#n: 이유`(최대 3개), 그다음 지금 다 자란 작물, 지금 마른 칸, 계절.

## 8. 정의서와 달라진 점

| 항목 | 정의서·설계 | 구현 |
| --- | --- | --- |
| 규칙 검사 | K5: 검사 시각마다 | 바뀐 것이 없으면 다음 다 자람 뒤의 검사까지 건너뛴다. 결과는 같다 (개발 이슈 4) |
| `Ready` 이벤트 | K20: 진행 뒤 다 자란 칸이 남아 있을 때만 | 더해서, 동작 중인 수확 규칙과 수확기가 있는 구역은 알리지 않는다 (곧 거둔다. 개발 이슈 5) |
| 한국어 문구 | - | 장비·작물 이름 뒤 조사(이/가, 은/는)를 쓰지 않는 문장으로 만들었다 (개발 이슈 3) |
