## 4. 명령

| 명령 | 결과 |
| --- | --- |
| `build.bat` | `bin\lupin.exe` (약 121KB) |
| `build.bat test` | `bin\tests.exe` 빌드 후 실행. `[OK] 25 passed, 0 failed` |
| `bin\lupin.exe` | 게임. 콘솔이 없으면(출력 리디렉션 등) 안내를 출력하고 종료 코드 1 |
| `bin\lupin.exe --frame [en\|ko] [cands\|prompt\|folded\|first]` | 예시 상태의 화면 한 장을 글자로 출력 (콘솔 불필요) |
| `bin\lupin.exe --sprites` | 도트 일람을 터미널에 색으로 출력 |
| 환경 변수 `LUPIN_HOME` | 저장 폴더를 바꾼다 (개발·테스트용). 기본은 `%LOCALAPPDATA%\LupinFarm` |

## 5. 구현 요약

| 영역 | 구현 |
| --- | --- |
| 메인 루프 | `WaitForSingleObject(입력, 30ms)` → 입력 처리 → 보스키 확인 → 시간 진행 → 30초마다 저장 → 바뀐 게 있거나 1초가 지나면 그리기 |
| 시간 | 실제 경과(UTC) × 60 ÷ 배속을 누적해 정수 게임 분만큼 진행. 5분 넘는 공백은 상한 2시간으로 처리하고 `Offline` 이벤트 |
| 성장 | `성장 += min(물 끝, 진행 끝) − 진행 시작`. 한 번의 진행에서 다 자란 칸은 `Ready(구역)`, 물이 끊긴 칸은 `Dry(구역)` 이벤트 |
| 화면 출력 | 셀 버퍼 → 바뀐 칸만 `ESC[줄;칸H` + 트루컬러 + 글자. 한 프레임을 `WriteConsoleW` 한 번(8K 글자 단위)으로 쓴다. 그리는 동안 커서를 숨기고 끝나면 입력창 위치에 둔다 |
| 도트 | 칸 하나 8×8 → 글자 8칸 × 4줄. 위·아래 픽셀 색이 같으면 공백 + 배경색 |
| 입력 | `ReadConsoleInputW`로 키(가상 키 + 글자 + 수정키), 마우스(왼쪽 누름 시작, 휠), 크기 변경 |
| 입력창 | 직접 만든 한 줄 편집기. 커서보다 길면 왼쪽을 밀어 보여 준다 |
| 자동완성 | 명령 17종, 명령별 인자(작물, 범위, 농기구, 구역, 설정 값). 최대 6줄. 단어를 치는 중일 때 Enter·Tab은 채우기, 빈 자리에서 Enter는 실행 |
| 선택지 | 비용 1,000G 이상 또는 골드 절반 이상인 농기구·땅 구매, `/reset`(두 번) |
| 보스키 | 별도 스레드에서 `RegisterHotKey` + `GetMessage`. 눌린 횟수가 홀수면 전환. 보스 모드에서는 대체 화면에서 나와 출력을 멈춘다 |
| 저장 | `save.json`, `profile.json` (PascalCase 키). `.tmp`에 쓰고 `File.Replace`로 바꾸며 `.bak` 유지. 명령 뒤, 30초마다, 종료·창 닫기(`CTRL_CLOSE_EVENT` 등) 때 |
| 언어 | 로그는 추가될 때의 언어로 문구를 고정한다. 헤더·패널·안내는 바로 바뀐다 |
| 종료 | 저장 → 보스키 해제 → 대체 화면 나가기 → 가짜 프롬프트 줄 지우기 → 콘솔 모드·탭 제목 복구. 예외는 `error.log`에 남긴다 |

## 8. 사용자 확인 항목

PowerShell 탭에서 `bin\lupin.exe`를 실행해 확인한다.

| 번호 | 확인 | 방법 |
| --- | --- | --- |
| U1 | 키 입력 | 명령 입력, `↑` `↓` 이전 명령, `Tab` 자동완성, `Esc`, `PgUp`/`PgDn`, `F2` |
| U2 | 마우스 | `◀` `▶`, 아래 테두리 점, 밭 클릭(좌표 입력), 로그 휠 |
| U3 | 보스키 | `Ctrl+Alt+H` → 프롬프트 한 줄만 보임 → 다시 눌러 복귀. 다른 창에 포커스가 있어도 동작 |
| U4 | 종료 | `Ctrl+C` 두 번 또는 `/exit` 뒤 PowerShell 프롬프트가 정상으로 돌아오는지, 탭 제목이 원래대로인지 |
| U5 | 다시 실행 | 끄고 몇 분 뒤 켜면 환영 상자에 부재 중 요약이 나오는지 |
| U6 | 한국어 | `/config lang ko` 뒤 패널·표 정렬 |
