## 3. 저장 형식

`save.json`에 두 필드가 생겼다. M1 세이브를 불러오면 `Normalize()`가 채운다 (시세 계수 1, 창고 Lv0).

```json
"Market": {
  "turnip": { "F": 0.93, "Yesterday": 1.0 },
  "corn":   { "F": 1.01, "Yesterday": 0.97 }
},
"Rng": 1074903999
```

`Rng`는 M1부터 있었고 M2부터 실제로 쓴다.

## 4. 구현 요약

| 영역 | 구현 |
| --- | --- |
| 하루 시작 | `Engine.Advance`가 성장 계산 뒤 `(t0, t1]` 안의 06:00마다 `Market.DailyUpdate`를 부른다. 계절이 바뀐 날을 `SeasonStarts`에 담는다 |
| 시세 갱신 | `어제 ← f`, `f ← clamp(f + 0.3(1 − f) + 0.08 N(0,1), 0.5, 2.0)`. 작물 순서는 `Content.Crops` |
| 판매 | `Market.Quote`: 하한 0.5에 닿기 전 개수 `k = floor(ln(0.5/f)/ln 0.998) + 1`, 합 = `f(1 − 0.998^m)/(1 − 0.998) + (n − m) × 0.5`. `Market.Sell`은 계수를 내린다 |
| 단가 | `max(1, 반올림(기준가 × f × 계절 배수))`. 제철 아님 1.3배 |
| 계절 | `/plant`는 제철이 아니면 오류. 재수확은 제철일 때만. 바뀌면 `● Season(…)` 이벤트와 제철 작물 |
| 표 | `Joined.Row(Pad(…), …)`로 열을 만들고, 화면에서 한글 2칸 폭으로 채운다 |
| 밤·계절 색 | 농장 영역만. 풀(g, G)은 계절 색, 밤에는 모든 색 × 0.55 |

## 5. 명령 (M2에서 추가·변경)

| 명령 | 결과 예 |
| --- | --- |
| `/market` | `● Market(Spring 4 · 14:00)` + 해금한 작물 표 + `5 more crops · /unlock to grow them` |
| `/inv` | `● Inventory(storage 28/40)` + 작물별 수량·단가·평가액 + `total … if sold now` + 씨앗 |
| `/map` | `● Map(2 fields)` + 구역별 표 (`*` = 보는 구역) |
| `/unlock potato` | `● Unlock(potato)` `⎿ -200G · gold 300G` + 계절·씨앗·판매가·성장 기간 (+ 재수확 주기) |
| `/upgrade storage` | `● Upgrade(storage)` `⎿ storage 40 → 80 · -400G · gold …` |
| `/sell turnip 30` | `⎿ +874G · avg 29G · price 30G → 28G · gold …` |
| `/shop` | 씨앗, 해금, 농기구, 창고, 땅 |

## 6. 테스트 (M2 추가분)

| 묶음 | 테스트 |
| --- | --- |
| `MarketTests` | 시작 단가(봄 옥수수 195G), 같은 시드 → 같은 시세, 500일 동안 범위 유지, 100개 판매 = 1개씩 합, 하한 0.5 |
| `SeasonTests` | 제철만 심기, 심은 작물은 계절이 바뀌어도 자람, 재수확은 제철만, 계절 이벤트 |
| `ShopTests` | 해금(비용·투자액), 창고 업그레이드(비용·최대), 표 명령, 판매 후 시세 하락, 시세·난수 저장 왕복 |

M1 테스트 중 봄에 옥수수·당근을 심던 2개는 순무로 바꿨고, 농사 한 바퀴의 판매 금액은 견적과 같은지로 바꿨다.
