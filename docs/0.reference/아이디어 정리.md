# 아이디어 정리

작성일: 2026-11-26

사용자 아이디어를 정리한 문서다. 기획·설계(`1.architecture/`)의 출발점이며, 조사 결과는 같은 폴더의 `위장형 게임 장르 조사.md`, `생활 시뮬·RPG 메커니즘 조사.md`, `명령어 농장 컨셉 분석.md`, `기술 스택 조사.md`에 있다.

## 1. 주제

업무 시간에 들키지 않고 할 수 있는 게임 **Lupin Farm**을 만든다. 프로젝트 이름 `wall-geop-lupin`은 "월급루팡"에서 따왔다.

| 날짜 | 사용자 요청 |
| --- | --- |
| 2026-11-26 | 바탕화면을 기반으로 한 게임 |
| 2026-11-26 | PowerShell 환경 같은 느낌의 도트 RPG, 또는 동물의 숲·스타듀 밸리 같은 생활 시뮬(타이쿤)도 고려 |
| 2026-11-26 | 다른 방향 하나 더: Claude Code 같은 화면에서 명령어로 진행하는 농사 전용 타이쿤 (방향 C) |
| 2026-11-26 | 방향 C로 진행. 이름 Lupin Farm, 영어 기본(한국어 옵션), 프레스티지 + 최고 기록·날짜별 자산 랭킹 |

## 2. 목적

- 일하는 동안 게임이 알아서 진행되고, 틈날 때 잠깐씩만 한다.
- 지나가는 사람이 화면을 봐도 게임인지 알아채지 못하게 한다.
- 집중하지 않아도 되는 게임이다. 업무 흐름을 끊지 않는다.

## 3. 사용자

| 사용자 | 설명 |
| --- | --- |
| 본인 | Windows 11 업무용 PC 사용자 1명. 회사 PC라서 설치 권한이 없거나 보안 프로그램 제약이 있을 수 있다 |

## 4. 들키지 않기 위한 조건 (설계 원칙)

장르보다 이 네 가지가 더 중요하다. 모든 기능은 이 원칙을 지켜야 한다.

| 번호 | 조건 | 설명 |
| --- | --- | --- |
| P1 | 소리·큰 움직임 없음 | 기본은 무음이다. 화면이 번쩍이거나 화면 전체를 덮는 효과를 쓰지 않는다 |
| P2 | 언제든 멈춤 | 조작은 짧게 끝나고, 실시간 반응을 요구하지 않는다. 자리를 비워도 손해가 없다 |
| P3 | 평소에는 안 보임 | 업무 창 뒤(바탕화면 레이어)에 숨어 있거나, 업무 화면처럼 보인다 |
| P4 | 보스키 | 단축키 한 번에 즉시 숨긴다. 어느 창에 포커스가 있어도 동작한다 |

## 5. 방향

세 방향을 비교했고, **방향 C로 진행한다** (사용자 결정 2026-11-26). 비교 근거는 `위장형 게임 장르 조사.md` 4~5절에 있다.

| 방향 | 한 줄 요약 | 상태 |
| --- | --- | --- |
| A. 바탕화면 생태계 | 아이콘 뒤 배경에서 작은 세계가 저절로 자란다. 조작은 트레이에서 한다 | 보류 |
| B. PowerShell 도트 생활 시뮬 | PowerShell 창 안에서 도트로 그린 농장·마을을 캐릭터로 돌아다니며 가꾸고, 턴제 던전을 탐험한다 | 보류 |
| **C. 명령어 농장 타이쿤 (Lupin Farm)** | Claude Code 같은 화면에서 영어 슬래시 명령어로 농사짓고, 팔고, 투자하고, 자동화한다. 위쪽은 도트 농장, 아래쪽은 명령어와 로그 | **진행** |

### 5.1 방향 C 기능

상세는 `명령어 농장 컨셉 분석.md`에 있다.

| 번호 | 기능 | 설명 |
| --- | --- | --- |
| C1 | Claude Code 같은 화면 | 위 도트 농장 영역, 아래 로그, 둥근 테두리 입력창, `●` `⎿` 결과 줄, `✻` 스피너. 진짜 PowerShell 탭 안에서 돈다 |
| C2 | 도트 농장 영역 | 반쪽 블록 도트. 밭 한 칸 8×8 픽셀, 구역 하나 10칸 × 3줄. 고정 높이 14줄 |
| C3 | 슬래시 명령어 | `/plant`, `/water`, `/harvest`, `/sell`, `/buy` 등. 자동완성, 이전 명령, 번호 선택지 |
| C4 | 배속 시간 | 실제 시간에 배속을 곱해 흐른다 (예: 실제 1분 = 게임 1시간). 물을 안 줘도 시들지 않고 성장만 멈춘다. 꺼져 있던 시간은 상한까지 반영 |
| C5 | 구역(페이지) 확장 | 칸·줄 구매 → 새 구역. `/field`, `PgUp`/`PgDn`, 화면 양옆 `◀` `▶` 마우스 클릭으로 이동 |
| C6 | 농기구 | 레벨이 오를수록 명령 하나로 처리하는 범위가 넓어진다 (한 칸 → 한 줄 → 구역 전체) |
| C7 | 작물·계절 | 계절마다 심을 수 있는 작물이 다르다. 비싼 작물일수록 오래 걸린다 |
| C8 | 시세 | 매일 바뀌는 시세, 판매 압력, 창고에 보관했다가 팔기 |
| C9 | 장비형 자동화 | 스프링클러, 자동 수확기, 자동 파종기, 출하함, 자동 구매기, 온실, 농장 컨트롤러, Caretaker |
| C10 | 규칙형 자동화 | `/auto add when f1 ready do harvest`. 규칙 행동은 해당 장비가 있어야 쓸 수 있다 |
| C11 | 무한 성장 | 지수 비용 업그레이드, 큰 숫자 표기, 도감·업적 |
| C12 | 위장 | `/hide`로 농장 영역 접기, 보스키로 평범한 프롬프트 화면 |
| C13 | 기록·랭킹 | 점수 = 총자산. 판마다 게임 날짜 체크포인트 기록, 실제 날짜별 기록, 최고 기록. `/records`, `/rank` |
| C14 | 프레스티지 | Lupin Bloom(제안): 농장을 초기화하고 Fertility를 받아 영구 보너스를 산다. 기록은 남는다 |
| C15 | 문구 언어 | 영어 기본. `/config lang ko`로 한국어. 명령어는 항상 영어 |

### 5.2 방향 A 기능 후보 (보류)

| 번호 | 기능 | 설명 |
| --- | --- | --- |
| A1 | 바탕화면 생태계 | 바탕화면 아이콘 뒤 배경 레이어에서 작은 세계가 시간이 지나며 자란다 |
| A2 | 방치형 진행 | 보고 있지 않아도 진행된다. 앱이 꺼져 있던 시간도 계산해서 반영한다 |
| A3 | 트레이 상호작용 | 먹이 주기, 건물 짓기 같은 행동은 트레이 메뉴나 작은 팝업에서 처리한다 |
| A4 | 조용한 알림 | 트레이 아이콘을 살짝 바꾸거나 윈도우 기본 알림 모양으로 알린다 |
| A5 | 보스키 | 전역 단축키로 즉시 숨기고, 다시 누르면 돌아온다 |
| A6 | 서브 모드 | 작업표시줄 펫, 로그 위장 RPG를 추가 모드로 붙인다 |

### 5.3 방향 B 기능 후보 (보류)

| 번호 | 기능 | 설명 |
| --- | --- | --- |
| B1 | PowerShell 탭에서 실행 | 진짜 Windows Terminal의 PowerShell 탭 안에서 돈다. 조작은 키보드만 쓴다 |
| B2 | 도트 렌더링 | 반쪽 블록 문자(`▀`)와 트루컬러로 픽셀을 그린다. 맵 + 상태 패널 + 로그 배치 |
| B3 | 텍스트 모드 | 같은 화면을 글자 타일과 로그로 바꿔 보여 준다 |
| B4 | 로그형 메시지 | 게임 메시지를 로그 형식으로 출력한다 |
| B5 | 실시간 농사·채집 | 작물과 날짜가 실제 시계에 맞춰 흐른다 |
| B6 | 턴제 행동·행동력 | 키를 누를 때만 캐릭터와 주변이 움직인다. 하루 행동량이 정해져 있다 |
| B7 | 마을·경제 | 주민 대화와 호감도, 상점, 도구 업그레이드, 수집 도감 |
| B8 | 턴제 던전 | 층을 내려가며 광석을 캐고 턴제로 싸운다 |
| B9 | 보스키 | 평범한 PowerShell 프롬프트 화면을 보여 준다 |
| B10 | 바탕화면 관상 모드 | 같은 세이브의 농장을 방향 A처럼 바탕화면 레이어에 띄운다 |

### 제외한 기능

| 기능 | 이유 |
| --- | --- |
| 아이콘 디펜스 (화면 전체 오버레이) | 재미는 가장 크지만 화면 전체를 쓰고 실시간 대응이 필요하다. P1~P3에 어긋난다 |
| 효과음, 배경음 | P1 |
| 실시간 액션, 타이밍 미니게임 | P2 |
| 온라인 랭킹 | 혼자 쓰는 로컬 게임이다. 랭킹은 내 기록끼리 비교한다 |
| 동물의 숲·스타듀 밸리의 이름, 캐릭터, 그래픽, 음악 | 실존 게임을 그대로 재현하지 않는다. 장르와 메커니즘만 참고하고 모두 오리지널로 만든다 |
| Claude Code의 로고, 이름 | 화면 배치와 분위기만 참고한다 |
| 회사 PC 감시·보안 프로그램 회피 | 범위 밖이다. "지나가는 사람 눈에 띄지 않는 것"까지만 다룬다 |
