# 생활 시뮬·RPG 메커니즘 조사

작성일: 2026-11-26 · 기준 문서: `아이디어 정리.md`

동물의 숲, 스타듀 밸리 같은 생활 시뮬레이션(농장·마을 타이쿤)과 도트 RPG의 핵심 메커니즘을 정리하고, 업무 시간에 하기 좋은지 평가한 결과다.

실존 게임은 **장르와 메커니즘 참고용**이다. 이름, 캐릭터, 그래픽, 음악, 맵은 쓰지 않고 모두 오리지널로 만든다.

적합도 표기: ◎ 잘 맞음 · ○ 바꾸면 맞음 · △ 부담 · ✕ 안 맞음 (설계 원칙 P1~P4 기준)

> 방향 C(명령어 농장, `명령어 농장 컨셉 분석.md`)는 이 문서의 농사·경제·시세·계절 메커니즘만 쓴다. 시간은 배속 방식이며, 1.1에서 ✕로 본 "빠른 게임 시계"를 어떻게 업무용으로 바꾸는지는 그 문서 4.2절에 있다.

## 1. 생활 시뮬레이션

### 1.1 시간 흐름: 가장 중요한 차이

| 방식 | 설명 | 대표 계열 | 업무 중 적합도 |
| --- | --- | --- | --- |
| 실제 시계 연동 | 현실 1시간 = 게임 1시간. 꺼 두어도 시간이 흐른다 | 동물의 숲 | ◎ 보고 있지 않아도 진행된다 (방치형) |
| 게임 내 시계 | 하루가 현실 약 14분. 화면을 보는 동안 계속 시간이 흐른다 | 스타듀 밸리 | ✕ 계속 조작해야 해서 P2에 어긋난다 |

→ **세계(작물, 날짜, 계절)는 실제 시계 연동**으로 하고, **캐릭터 행동은 턴제**로 한다. 턴제는 키를 누를 때만 캐릭터와 주변이 움직이는 방식이다. 출근할 때 심은 작물이 점심이나 퇴근 시간에 다 자라 있고, 화면을 떠나도 아무 일도 일어나지 않는다.

### 1.2 메커니즘

| 메커니즘 | 설명 | 적합도 | 업무용으로 바꿀 점 |
| --- | --- | --- | --- |
| 농사 | 심기 → 물 주기 → 자람 → 수확 → 판매. 작물마다 자라는 시간과 값이 다르다 | ◎ | 자라는 시간을 업무 일과에 맞춘다 (2시간, 4시간, 하루) |
| 행동력 | 하루에 할 수 있는 행동량이 정해져 있다 | ◎ | 하루 플레이 시간이 자연스럽게 제한돼 업무를 덜 방해한다 |
| 경제·업그레이드 | 판매 수익으로 도구, 밭, 집을 키운다. 큰 빚 갚기 같은 장기 목표 | ◎ | 타이쿤 요소의 중심 |
| 수집 도감 | 물고기, 벌레, 광석, 작물 도감 | ◎ | 장기 목표. 텍스트 목록이라 터미널과 잘 맞는다 |
| 계절·날씨 | 계절마다 작물과 이벤트가 바뀐다 | ○ | 실제 날짜와 연동할 수 있다 |
| 채집·낚시·벌레 잡기 | 맵에 랜덤으로 나타나는 자원 | ○ | 낚시의 타이밍 조작은 확률이나 턴제 선택으로 바꾼다 |
| 주민·호감도 | 대화, 선물, 호감도에 따른 이벤트 | ○ | 대화가 텍스트라 터미널과 잘 맞는다. 대사량이 많아 콘텐츠 부담이 있다 |
| 집·마을 꾸미기 | 가구 배치, 마을 확장 | △ | 해상도가 낮은 터미널 도트로 표현하기 어렵다. 범위를 작게 잡는다 |
| 광산·던전 | 층을 내려가며 광석 채집과 전투 | ○ | 턴제로 만들면 RPG 요소와 연결된다 (2절) |

### 1.3 업무 일과와 엮는 재미 요소 (후보)

| 요소 | 설명 |
| --- | --- |
| 출근 보너스 | 그날 처음 켜면 작은 보상 |
| 점심 장터 | 12~13시에만 열리는 상점 |
| 퇴근 정산 | 하루 수확과 판매를 요약해 보여 준다 |
| 방치 페널티 없음 | 주말이나 휴가로 오래 켜지 않아도 작물이 시들지 않는다. 회사 PC에서만 하는 게임이라 필수다 |

## 2. 도트 RPG

| 메커니즘 | 설명 | 적합도 | 업무용으로 바꿀 점 |
| --- | --- | --- | --- |
| 전투: 실시간 액션 | 키를 빠르게 눌러 피하고 공격 | ✕ | 쓰지 않는다 (P2) |
| 전투: 턴제 | 내가 행동해야 적도 행동한다 | ◎ | 전투 중에도 언제든 자리를 뜰 수 있다 |
| 로그라이크 던전 | 층이 랜덤으로 만들어지고, 한 판이 짧다 | ◎ | 한 판 = 10~15분 안쪽. 층마다 중간 저장 |
| 성장 | 레벨, 장비, 스킬 | ◎ | 농장에서 얻은 재료로 장비를 만들게 해 두 장르를 잇는다 |
| 인벤토리·제작 | 재료를 모아 아이템 제작 | ○ | 생활 시뮬과 공유한다 |
| 긴 스토리·퀘스트 | 대사와 연출이 많은 줄거리 | △ | 집중을 요구한다. 짧은 의뢰 단위로 바꾼다 |

## 3. 결론

- **생활 시뮬(농장·마을)을 메인**으로 한다. 실제 시계로 자라는 세계가 방치형 진행을 만들고, 행동력이 하루 플레이를 짧게 끊어 준다.
- **턴제 던전 RPG는 서브 콘텐츠**로 붙인다. 시간이 남을 때만 들어가는 곳이고, 농장 재료 ↔ 던전 보상으로 두 장르를 잇는다.
- 실시간 조작(액션 전투, 타이밍 미니게임)은 모두 확률이나 턴제로 바꾼다.
- 콘텐츠 양(작물, 주민, 아이템, 도트)이 가장 큰 부담이다. 첫 마일스톤은 **농사 한 바퀴(심기 → 물 주기 → 수확 → 판매)**로 좁힌다.
