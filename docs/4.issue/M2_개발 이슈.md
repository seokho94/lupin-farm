# M2_개발 이슈

작성일: 2026-11-26 · M2 개발 중 정한 해석과 문제. 항목은 현상 → 원인 → 조치 → 반영 순서로 적는다.

## 1. 실행 중인 게임 때문에 `lupin.exe`를 덮어쓰지 못함

- 현상: 빌드가 `CS0016: 출력 파일에 쓸 수 없습니다(다른 프로세스가 사용 중)`로 실패했다.
- 원인: 사용자가 M1 게임을 실행하고 있었다.
- 조치: 실행 중인 게임은 끄지 않았다. 실행 중인 exe도 이름은 바꿀 수 있으므로 `bin\lupin.exe`를 `bin\lupin.old.exe`로 바꾸고 새로 빌드했다. 실행 중인 게임은 그대로 돌고, 다음 실행부터 M2가 뜬다. `lupin.old.exe`는 게임을 끈 뒤 지워도 된다 (`bin/`은 git 제외).
- 주의: 옛 버전과 새 버전을 동시에 실행하면 같은 세이브를 번갈아 쓴다. 하나만 실행한다.
- 반영: CLAUDE.md 개발 명령

## 2. 줄여 쓴 골드가 `200KG`(킬로그램)처럼 읽힘

- 현상: `/shop`의 새 구역 가격이 `200KG`로 나왔다.
- 원인: 단위(K)와 골드 표시(G)가 붙는다.
- 조치: 10,000 이상으로 줄여 쓸 때는 띄어 `200K G`로 적는다. 10,000 미만은 `1,240G` 그대로.
- 반영: `src/Core/NumberFormat.cs`, `NumberFormatTests`, `../1.architecture/02_도메인 모델 및 데이터 포맷.md` 9절

## 3. 한국어 시세표 머리글이 한 칸 밀림

- 현상: "어제 대비"(9칸)가 열 폭 9와 같아, 칸 맞춤이 공백 하나를 붙이면서 "비고" 열이 한 칸 밀렸다.
- 조치: `today` 열 폭을 11로 넓혔다.
- 반영: `src/Core/Commands.cs` (`MarketTable`), 개발 명세 4.1절

## 4. M1 테스트가 봄에 옥수수·당근을 심고 있었음

- 현상: 계절 제한을 넣자 M1 테스트 2개가 실패했다.
- 원인: 옥수수(여름·가을), 당근(가을)은 봄에 심을 수 없다.
- 조치: 테스트를 순무로 바꿨다. 사용자 세이브에 M1에서 봄에 심어 둔 옥수수·당근이 있어도 끝까지 자란다 (FR-FARM-09).
- 반영: `tests/GameTests.cs`

## 5. 시작 계절의 무료 작물이 순무 하나

- 판단: 무료 작물은 순무(봄), 옥수수(여름·가을), 당근(가을)이라 봄에는 순무만, 겨울에는 해금 없이는 아무것도 못 심는다. 02 3.2절의 의도(겨울 = 온실 동기)대로 두었다. 버섯(300G)을 해금하면 겨울에도 심을 수 있다.
- 조정할 곳: `src/Data/Content.cs`의 `Crops`. M5(밸런스)에서 다시 본다. 사용자 확인 항목 U4.

## 6. 감자 알이 흙색에 묻힘

- 현상: 도트 일람에서 감자 알(`#B08850`)이 마른 흙(`#8B6B47`)과 구분이 잘 안 됐다.
- 조치: `#D6B272`로 밝혔다.
- 반영: `src/Data/Sprites.cs`

## 7. 도트 확인 방법

- `--sprites`는 터미널 창이 필요해서, 창을 띄우지 않으려고 PowerShell에서 `lupin.exe`를 어셈블리로 불러 `Sprites`를 PNG로 그려 확인했다 (작물 10종 × 단계 4 + 계절 3 + 밤). 별도 도구 파일은 만들지 않았다.
